# 禁漫天堂 v2.5：发现页标签改成 91Hub 式点击伸缩/扩展

> 261128 用户要求「标签参考91hub的格式，用点击伸缩，点击扩展那样的样子」，并追加指出「顶点小说api源的发现列表也有这样的」。
> 本版直接照搬技能库既有《方法-发现页本源搜索框与可伸缩分组列表.md》与 App 内 `🐾顶点小说API` 的 `MYKINDS()` 范式，不另造方案。

## 一、机制（与 91Hub / 顶点小说API 完全一致）

发现页 JSON 数组里加一个折叠条：

```js
{
  title: (open ? '▾ ' : '▸ ') + title,
  url: '',
  type: 'button',
  action: '(function(){var c={};try{c=JSON.parse(String(source.getVariable()||"{}"))||{};}catch(e){}'
        + 'c["jmV2Tag_mv"]=c["jmV2Tag_mv"]?0:1;'
        + 'source.setVariable(JSON.stringify(c));'
        + 'java.refreshExplore();})()',
  style: { layout_wrapBefore: true, layout_justifySelf: 'flex_start' }
}
```

求值时用同一个 `cfg` 决定是否 push 子项：

```js
var cfg={}; try{cfg=JSON.parse(String(source.getVariable()||'{}'))||{}}catch(e){}
function isOpen(k, def){ return cfg[k]===undefined ? def : cfg[k]!==0; }
```

三件事缺一不可：读变量 → 翻转写回 → **`java.refreshExplore()`**。少了第三项，变量变了界面不重绘，看起来就是「点了没反应」。

## 二、与 jmtt 原有线路变量不冲突（本次新增实锤）

- `source.put/get(key)` → CacheManager 键 `v_<书源URL>_<key>`，jmtt 的 `jmV2Host` / `jmV2LineN` / `jmV2LatN` / `jmV2ImgProxy` 走这条。
- `source.getVariable()/setVariable()` → CacheManager 键 `sourceVariable_<书源URL>`，折叠状态走这条。

两者是**不同命名空间**，不会互相污染。但折叠条 action 仍必须先 `JSON.parse` 原串、只改本次 key、再 `JSON.stringify` 写回，因为用户可能在该键里放了其它配置（顶点小说API 踩过 `c={}` 覆盖用户配置的坑）。

## 三、jmtt v2.5 落地细节

1. 标签下拉 `addSel(T+'标签', ...)` 删除，改成 `addTagEntries()`。
2. 每个类型一个折叠键：`jmV2Tag_comic` / `jmV2Tag_novel` / `jmV2Tag_mv` / `jmV2Tag_drama`，默认收起（`defOpen=false`）。
3. 展开后每个标签是一条 `type:'url'` 直达入口：
   `{{jmHost(source)}}/{seg}/tag/{encoded}{{page>1?('/'+page):''}}?{status,length,subtitle,duration,sort}`
4. 标签数量从 v2.4 的「视频前40」补全为站点标签页全量：**comic 20 / novel 20 / mv 192 / drama 5**。折叠后不再有下拉过长的问题。
5. 站点实测 tag 与分类路径不能叠加（`/novel/all/dsjq?tag=制服` 摘要仍是「都市激情·全部」）。v2.4 是「选中标签后隐藏分类入口」；v2.5 标签改成点击直达，**不需要隐藏分类**，折叠条标题和展开后的静态提示行直接写明「标签与分类不可叠加」。
6. 分类/榜单仍常驻，保证任何折叠状态下 `exploreKinds()` 数组里都有非空 URL——`CheckSourceService` 会取第一个非空 url 做校验，全部折叠且没有常驻 URL 会被误判「发现规则为空」（顶点小说API 注释里的坑）。
7. 标签芯片 `style:{}`，不写 `layout_flexBasisPercent` / `layout_flexGrow`，让 Flexbox 按文字自适应宽度并自动折行（顶点 v5.4 修正：写死 basis 反而造成「3字榜单占整行」「首字…」）。
