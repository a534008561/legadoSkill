# 补充-禁漫天堂 v2.2：状态与字幕也改为下拉

> 261128 用户要求「状态和字幕改成下拉」。v2.1 里小说/漫画的「状态」、视频的「字幕」是 toggle；v2.2 全部改为 select，发现页只保留 select 作为筛选控件（分类/榜单仍是直入口）。成品 `examples/禁漫天堂_jmtt_v2.2_全下拉筛选.json`。

## 改动点

- `小说状态`、`漫画状态`、`视频字幕` 三行由 `type:'toggle'` 改成 `type:'select'`（chars 与 default 不变）。
- 其余控件本来就是 select：小说字数/排序、视频时长/排序、漫画排序、短剧时长/排序；顶部类型也是 select。
- 筛选值仍烘焙进分类入口 URL，select 的 `action: "java.refreshExplore()"` 保持不变（ExploreAdapter 在用户选择后先写 `infoMap[title]` 再执行 action，LT/E 源码均如此）。
- toggle 改 select 不影响取值：`infoMap` 里已有的「连载中/中文字幕」等值都在 chars 内，直接被选中。

## 验证

- qjs 模拟 `infoMap={"类型":"小说","小说状态":"连载中"}`：前 4 行类型均为 select，列表入口标题带「（连载中）」筛选标记。
- LT(1122) + E(1125) `saveBookSource` 200；LT `check_source` 1/1。
