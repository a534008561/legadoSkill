## 一、官方支持的三条简介通道（源码级）

`BookInfo.kt:125` —— **若 `intro`（trimStart 后）以下列三种标记之一开头，book.intro 原样保存、跳过 `HtmlFormatter.formatIntro` 净化**；`Book.getDisplayIntro()` 原样返回；`BookInfoActivity.showBookIntro()` 分流渲染：

| 标记 | 渲染层 | 能做什么 | 关键源码 |
|---|---|---|---|
| `<usehtml></usehtml>` | **TextView**（RichText） | 富文本 + **`<button>@onclick:JS`** 官方按钮 | `TextViewTagHandler` 按 `@onclick:`（split limit=2）拆按钮名 + JS |
| `<useweb></useweb>` | **真 WebView**（`WebViewPool.acquire`） | 完整 HTML/CSS/JS、DOM 事件、`setInterval` 常驻 | `loadDataWithBaseURL(bookUrl, intro.substring(8, lastIndexOf("<")), "text/html")`；注入 `java`(WebJsExtensions) + `source`(BaseSource) + `cache` |
| `<md></md>` | Markdown | 排版为主，交互弱 | — |

按钮点击链路：

```
<button ... @onclick:JS>
  → BookInfoViewModel.onButtonClick(activity, name, click)
      source.evalJS(click) {
        put("java",   SourceLoginJsExtensions(activity, source));   // ★ 完整 JsExtensions！
        put("book",   book);  put("result", null);
      }
```

**这是本篇最重要的一条事实**：`@onclick` 跑的 JS **不看 `@JavascriptInterface` 注解**（它是 Rhino 直接 eval），所以 `java.startBrowser` / `java.openVideoPlayer` / `java.ajax` 这些**在 useweb 页面里调不到的方法，在 `<usehtml>` 的按钮里全部能调**。

## 二、★选型决策树

```
需要在书籍页放一个可点的东西？
│
├─ 只要"点一下执行一段 JS"（开内置浏览器/播放器/取签名直链/复制）
│    └─────────────────────────────────► 通道 A：<usehtml> + <button>@onclick:   ★首选
│         （主题色圆角按钮，轻量，无 WebView，最稳）
│
├─ 需要"活的界面"：会随时间/事件自己变（切 P 跟随、异步测速进度、可折叠目录）
│    └─────────────────────────────────► 通道 B：<useweb> 面板 + setInterval 轮询
│         （代价：WebView、桥能力受限、图片有 blockNetworkImage 风险）
│
├─ 需要"点一下就打开另一本书"
│    └─────────────────────────────────► 通道 E 嵌进 A 或 B：<a href="legado://import/addToBookshelf?src=…">
│         （深链在 A/B/E 三处都能跳，见第八节）
│
├─ 需要在【阅读正文页】放按钮（每章都能点）
│    └─────────────────────────────────► 通道 C：正文 <usehtml>（BookContent.kt:243 + TextChapterLayout:689）
│         或虚拟章节（把外链做成目录条目，点章节即触发）
│
├─ 需要列表形态的"功能入口/聚合搜索"（不需要是书）
│    └─────────────────────────────────► 通道 D：订阅源（RssSource.ruleArticles 返回 [{name,url}]）
│
└─ 需要给用户一个"大源导入"入口
     └─────────────────────────────────► 通道 E：java.openUrl('legado://import/bookSource?src=…')
```

**两条排除规则**：

1. **`A` 与 `B` 互斥**（同一 `intro` 只能有一个前缀）。要按钮 → A；要活界面 → B。
   hanime1 的做法是**A/B 双份实现 + 登录 UI 开关**（`webt` 切 `h1web=web/off`，off 走 `H1OLD()` 的 v3.1 `<usehtml>` 快照，12 个 `@onclick` 按钮）——**降级路径要预先留好**。
2. **列表字段的 `intro` 必须保持纯文本**。`ruleSearch.intro`/`ruleExplore.intro` 是纯文本展示，塞标签会**把 `<usehtml>` 露出来**。只有 `ruleBookInfo.intro` 才能写标记。

## 四、通道 A：`<usehtml>` + `<button>@onclick:`

### 最小骨架

```javascript
// ruleBookInfo.intro —— 以 <usehtml> 开头、以 </useweb> 之前所有用户文本必须转义
@js:
var Q = String.fromCharCode(34), NL = String.fromCharCode(10);
function esc(s){ s = String(s == null ? '' : s);
  s = s.split('&').join('&amp;').split('<').join('&lt;')
       .split('>').join('&gt;').split(String.fromCharCode(39)).join('');   // ★标题里删单引号
  return s; }
var t = esc(title), url = esc(bookUrl);
var h = '<usehtml>';
h += '<b>' + t + '</b>' + NL;
h += '<font color=#8a8a8a>本章无正文（疑似版权限制）</font>' + NL;
h += '<button>🌐 在内置浏览器打开@onclick:java.startBrowser(' + Q + url + Q + ',' + Q + t + Q + ')</button>';
h += '<button>▶ 播放直链@onclick:' + playJs(idx) + '</button>';
h += '<hr><font color=#9a9a9a>' + desc + '</font>';
h += '</usehtml>';      // ★必须最后，中间不能再有裸 '<'
return h;
```

渲染效果：主题色圆角 `RoundedButtonSpan`，**内联流式排布**；支持 `<b> <br> <font color=#hex> <hr>`；`&nbsp;` 可做按钮间隔。

### 实时取签名直链（防过期）——黑料网生产模式

`<usehtml>` 是**快照**（存进 `book.intro`），但 m3u8 签名只有 ~1 小时。解法：**把"取直链"放进 onclick，点击时现取**。

```javascript
// onclick（注意：禁裸 < 与 &&，用 size()-1>=idx 与三元规避）
var h = java.ajax('https://site/archives/123.html');
var ds = Packages.org.jsoup.Jsoup.parse(String(h)).select('div.dplayer');
var u = '';
if (ds.size() - 1 >= 0) {                       // ★不用 ds.length && ...
  try {
    var c = JSON.parse(String(ds.get(0).attr('config')));
    var v = c.video;
    u = String(v ? v.url : '');                   // ★不用 &&
  } catch (e) {}
}
if (u) { java.openVideoPlayer(u, '标题'); } else { java.toast('未取到直链'); }
```

### `@onclick` 的编码纪律（三条，全踩过）

1. **onclick 里禁裸 `<` 和 `&&`**（HTML/XML 解码风险）→ 用 `size()-1>=idx`、三元 `v ? v.url : ''`；
2. **onclick 字符串用单引号包裹，用户文本必须删掉单引号**（标题里的 `'` 会截断 JS）；
3. **`&` `<>` 一律转实体**（`esc()`），因为最后一个 `<` 会被截断逻辑吃掉。

## 五、通道 B：`<useweb>` 活视图面板

适用：会随时间变化的界面。两个生产案例：

- **hanime1 v3.2~v3.9**：播放页切 P → 简介面板 1.5s 轮询 `source.get('h1now')` → 自动刷新封面/标题/标签/直链；
- **wn10.shop**：详情页图床状态卡片，打开即逐个 `java.head` 测速 img1~5，显示 `✔通 xxms / ✘不通`，点行 = 固定线路。

### 关键机制

```
BookInfoActivity.showBookIntro() 对 <useweb>：
  WebViewPool.acquire() → WebView 塞进 tv_intro_container(FrameLayout wrap_content)
  addJavascriptInterface(source, "source")            // BaseSource：get/put 有 @JavascriptInterface
  addJavascriptInterface(WebJsExtensions(it,null,webView), "java")   // ★activity = null
  onPageStarted 注入 try{var cache=…,source=…,java=…;}catch(e){}     // ★所以页面里先 try
  loadDataWithBaseURL(bookUrl, intro.substring(8, intro.lastIndexOf("<")), "text/html")
```

三条由此推出的纪律：

1. **`activity=null` ⇒ 任何需要 activity 的桥方法静默失败**（`java.request("run"/"headAwait")` 的 Promise **永不 resolve**）。只能用同步桥：`ajax/get/post/head/connect/getString/getStringList/setContent/toast/longToast/log/get/put`。
2. **`substring(8, lastIndexOf("<"))`**：`<useweb>` 前面不能有内容；`</useweb>` **必须是最后一个标签**（前面所有用户文本要 `esc()`；页面里不能再有别的 `<`）；
3. **`java.ajax` 会冻结 WebView JS 线程**（425KB 页 0.66~6.8s）→ **切 P 之类的高频动作必须零网络**：数据预置在 `h1info`/初始 JSON 里，面板只读内存改 DOM。

### 与规则侧通信（★双向同键）

```javascript
// 规则侧（callBackJs / content）
source.put('h1now', entryVid + '|' + playVid + '|' + Date.now());   // CacheManager: v_{sourceKey}_h1now
// 面板侧（页面 JS）
var now = String(source.get('h1now') || '');                          // BaseSource.put/get 有注解，同一键空间
```

配合 `ruleContent.callBackJs` + `eventListener=true`（`SourceCallBack.callBackBookInternal`），**切集必触发**（`upDurIndex() → saveRead()`），且**不受正文缓存影响**（内容命中缓存时 content 规则不跑，所以两处都要写）。

> `java.refreshBookInfo()` 在播放页是**空操作**（`VideoPlayerActivity` 不监听 `REFRESH_BOOK_INFO`）——Legado 没有刷新播放页简介的官方通道，只能靠 useweb 活视图绕过。

### 面板内的图片（回指图片篇）

`BackstageWebView.createWebView()` 硬写 `blockNetworkImage=true`，`WebViewPool` 只在 `release()→onPageFinished` 复位 → 池化 WebView **可能带着"屏蔽网络图片"就被 acquire**。
→ 简介里的封面要在**规则侧下载 + base64 转 `data:` 内嵌**（见[图片排查篇第四节](方法-图片不显示排查总表-加密之外的三条路.md)），并组候选链 `data → pu → https → http → 换 CDN 主机`，`onerror` 逐个试 + 状态行回显。

## 六、通道 C：正文虚拟章节按钮

两种做法，按需组合（zhaoshu 用了 B+C 双保险）：

### C1 正文里放 `<usehtml>`（官方支持）

`BookContent.kt:243` 有占位处理、阅读器 `TextChapterLayout:689` 走同一个 `TextViewTagHandler` → **正文里 `<button>@onclick:` 同样可点**。

```javascript
"content": "@js: return '<usehtml>' + body + NL
  + '<button>📖 打开这本书@onclick:java.openUrl(' + Q + deep + Q + ')</button>' + '</usehtml>';"
```

约束同 A（前缀必须开头、最后 `<` 截断、onclick 禁裸 `<`/`&&`）。

### C2 虚拟章节（把外链做成目录条目）

```javascript
// chapterList：为每条外部网址造一个虚拟章
data-rid = 'open-' + encodeURIComponent(网址)
chapterUrl = baseUrl + '#reply-' + data-rid      // ★fragment 不进 HTTP、天然唯一
// ruleContent：rid.indexOf('open-')===0 → decodeURIComponent → java.openUrl(深链) → 返回说明文字
```

⚠️ 必须 `split('#')[0]` 清洗上游带来的意外 fragment（hlwf6 的 `#browser` 污染案）。

## 七、通道 D：订阅源（RSS）整页 HTML

需要"列表即功能入口"（如聚合搜索、求书榜）时，订阅源比书源顺手：

```
RssSource.ruleArticles   → @js: 返回 [{name,url}] 列表
RssSource.ruleContent    → @js: 返回【整段带 <style> 的 HTML】（Legado 走 loadDataWithBaseURL 渲染）
                              ⇒ 链接可点即跳（深链）
RssSource.nextContentUrl / ruleNextPage(=="PAGE" 复用 sortUrl) / singleUrl / loadWithBaseUrl
RssSource.injectJs       → 真实站点页里注入按钮（拦截点击改跳深链）
RssSource.style / articleStyle / shouldOverrideUrlLoading
```

三条注意：

1. `ruleLink` 走 `isUrl=true`（`RssParserByRule`）→ **`attr('href')` 相对路径即可**，别用 `absUrl`；
2. `injectJs` 的"网页打开"链接要打 `data-nojump`，否则被自己的劫持逻辑再次改写；
3. **MCP `save_source` 只处理书源**；订阅源若 `sourceUrl` 与某书源 `bookSourceUrl` 同值会被当成同名书源**覆盖** → 订阅源只能手动导入。`sourceIcon` 别用 SVG。

## 八、通道 E：`legado://` 深链（开书 / 导入源）

### E1 点击网址 → 直接打开阅读里对应的书详情页

```
legado://import/addToBookshelf?src=encodeURIComponent(书籍网址)
```

链路（源码已核）：

```
shouldOverrideUrlLoading → handleCommonSchemes(scheme = legado|yuedu)
  → OnLineImportActivity(path=/addToBookshelf) → AddToBookshelfDialog
  → 三级匹配书源：
     ① bookUrl 尾部 UrlOption {"origin":"<bookSourceUrl>"}
     ② 域名 → getBookSourceAddBook
     ③ 遍历启用书源的 bookUrlPattern 正则
  → WebBook.getBookInfoAwait → startActivity<BookInfoActivity>
  全失败 → toast「未找到匹配书源」
```

AndroidManifest 已注册 `scheme=legado|yuedu`（`exported+BROWSABLE`）。

**★更稳的做法**（不依赖 WebView 的 `onCreateWindow`）：

```javascript
java.openUrl('legado://import/addToBookshelf?src=' + encodeURIComponent(bookUrl))
// help/JsExtensions.kt:1213 内部同样特判 legado://|yuedu:// → startActivity<OnLineImportActivity>
// 而 AnalyzeRule : JsExtensions ⇒ 普通书源规则 JS 里就能调深链，不必依赖订阅源
```

对比：`window.open(deepLink,'_blank')` 依赖 `onCreateWindow`，不稳。

### E2 大书源导入通道

`java.openUrl('legado://import/bookSource?src=' + encodeURIComponent(rawUrl))` → `ImportBookSourceDialog`。
流程与坑见[交付质量闭环第九节](方法-书源交付质量闭环.md)（dpaste 尾斜杠、429 只拉一次、REPLACE 不重复）。

### 放置规则（三条硬约束，源自 memory 16）

1. 按钮里**不要放 http(s) 链接**（`shouldOverrideUrlLoading` 对 http/https 返回 false → 内嵌 WebView **原地导航走**，按钮页丢失）；要留网址就写**纯文本**（长按复制），**只有深链用 `<a href>`**；
2. 单引号在 HTML 属性里写 `&#39;`；
3. 深链必须 `encodeURIComponent`，且**不要双重编码**。

## 九、桥能力清单：什么能调、什么调不到

| `java.openUrl(legado://)` | ✅ | ✅ | ⚠️ E 版走外部浏览器确认页 | ❌ | ✅ |
| `java.showBrowser` | ✅ | ✅ | — | ❌ | ✅ |
| `source.get/put(k,v)` | ✅ | ✅ | ✅（BaseSource 有注解） | ❌（source 未定义） | ✅ |

| `source.getLoginInfoMap()` | ✅ | — | — | — | ✅ |
| `java.request("run"/"headAwait")` | ✅（有 activity） | ✅ | ❌ **永不 resolve** | — | — |

| `java.clearTtsCache()` | — | — | — | — | ✅(HttpTTS) |

## 十、跨通道硬约束（六条）

| # | 约束 | 影响的通道 | 理由 |
|---|---|---|---|
| 1 | **`intro` 前缀必须是标记，且以闭合标记结尾** | A/B/C1 | `substring(9\|8, lastIndexOf("<"))` 截断逻辑 |
| 2 | **所有用户文本 `esc()`（`& < >` 转实体、标题删单引号）** | A/B/C1 | 同上 + onclick JS 定界 |
| 3 | **onclick 内禁裸 `<` 与 `&&`** | A/C1 | HTML/XML 解码 |
| 4 | **列表字段保持纯文本** | 全部 | `ruleSearch/Explore.intro` 不做标记渲染 |
| 5 | **页面/正文里不留 http 可点链接** | B/D | 会被原地导航吃掉，按钮页丢失 |
| 6 | **零双引号纪律（`fromCharCode(34)`），大 HTML 用 `@q@` 占位** | 全部 | MCP/传输层会破坏转义 |

## 十一、验证方法

### 11.1 `<usehtml>` / `@onclick` 的仿真闭环（hlwf6 v3.5 定型）

```
eval_js（绑定书源）：
① java.ajax 取真实详情页 + 伪造 result/baseUrl
② eval intro 规则文本 → 得 introStr
③ 断言：以 <usehtml> 开头、以 </usehtml> 结尾、button 数、onclick 数
④ 正则取出每个 @onclick 内容 → &amp; 等解码 → new Function(click) 编译校验
⑤ 直接 eval(click) —— ★真机观察是否真的弹出内置浏览器/播放器
   （完整复现 BookInfoViewModel.onButtonClick 的执行路径）
⑥ TextView 的最终渲染层仍需用户手机目视
```

### 11.2 `<useweb>` 面板 DOM 是否真被填上 → `java.webView` 探针

```javascript
java.webView(panelHtml, 'https://example.com/',
  '(function(){ return JSON.stringify({t: (document.querySelector(".title")||{}).textContent, '
  + 'imgs: document.images.length, ok: [].slice.call(document.images).filter(function(i){return i.naturalWidth>0;}).length}); })()');
```

- js 必须是**表达式**（IIFE）；顶层 `return` 报 Illegal return statement；`var a=x;` 语句式报 missing `)`；
- 空返回 → 内部重试 30+ 次后抛"js执行超时"（25~30s）→ 用 `window.__n` 自计数控制采样轮数；
- 顺带能验证第 4 节的 `blockNetworkImage`（网络图 `naturalWidth=0`、`data:` 正常）。

### 11.3 桥缺失时的显式降级

面板底部要能报"未找到脚本桥"（hanime1 实测：`typeof source === 'undefined'` 时给提示而非白屏）。`WebJsExtensions` 桥在 E 版/LT 版能力不同，用户装的可能是任何一个。

## 十二、避坑清单

| # | 坑 | 对策 |
|---|---|---|
| 1 | 用 `<useweb>` 放按钮，指望页面能调 `startBrowser` | 无注解 → 改用 `<usehtml>` 的 `@onclick` |
| 2 | 以为 useweb 能 `java.request('run')` | activity=null → Promise 永不 resolve |
| 3 | 用 `java.refreshBookInfo()` 刷播放页简介 | VPA 不监听 `REFRESH_BOOK_INFO`，空操作 → useweb 活视图 |
| 4 | 高频动作用 `java.ajax`（useweb 内） | 冻结 WebView JS 线程 → 数据预置 + 只读内存 |
| 5 | 正文缓存命中导致"跟随"不生效 | 双写：content 规则 + `callBackJs`(eventListener=true) |
| 6 | `<usehtml>` 前写了别的字 | 标记必须 trimStart 后位于开头 |
| 7 | 用户文本未转义 | 最后一个 `<` 截断 → 一切错乱 |
| 8 | onclick 里写 `&&` / `<` | 解码期就断，用三元与 `size()-1>=idx` |
| 9 | 标题含单引号 | onclick 提前结束 → 生成时删单引号 |
| 10 | 列表 intro 塞标记 | 露出标签 |
| 11 | useweb 里放 http 链接 | 原地导航，按钮页丢失 |
| 12 | 简介里放网络封面图当稳态 | `blockNetworkImage` 竞态 → data 内置 |
| 13 | 把大 data 图塞进有长度闸门的变量 | 静默丢弃（9000→400000） |
| 14 | 深链用 `window.open(_blank)` | 依赖 onCreateWindow → 用 `java.openUrl` |
| 15 | 虚拟章节 URL 不加 fragment | 同 URL 被合并 |
| 16 | fragment 未清洗 | 上游 `#browser` 污染章节 URL |
| 17 | 订阅源 sourceUrl 撞书源 bookSourceUrl | 被当成同名书源覆盖 |
| 18 | sourceIcon 用 SVG | 不显示 |
| 19 | A 通道当"实时"用 | 它是快照；直链/签名要在 onclick 里现取 |
| 20 | 只用一种通道 | 关键交互留 A/B 双份 + UI 开关（hanime1 模式） |
