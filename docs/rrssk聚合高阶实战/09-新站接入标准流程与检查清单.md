# 新站接入标准流程与检查清单（rrssk 家族模板）

> 以 www.xiakezww.com 实际接入为例，全程 10 分钟。适用于所有同族站点。

## 第 0 步：前置探测（eval_js / 浏览器）

```javascript
var H = {"User-Agent": "移动端UA"};
var home = String(java.get("https://www.xiakezww.com", H).body());
// ① 站点存活 + WAF 检查
//    waf=true → 需要换移动端UA重试或放弃
// ② 中转跳转提取（决定 searchUrl 是否需要适配）
var redir = home.match(/window\.location\.href='([^']+)'/);  // rrssk家族格式
// 或 home.match(/window\.open\('([^']+)'/)                    // 菠萝猫格式
// 实测输出: https://www.rrssk.com/005C.html  ← 中转页，每站唯一
```

## 第 1 步：识别发现页模板

```javascript
var b = String(java.get(host + "/list-1-1/", H).body());
// 特征串速查（按顺序检测，命中即模板）：
// ul.flex          → xinghuowxw
// speList          → shoudaxsw
// "list dList"     → kelexs
// picZList         → shuwuwan
// proIList         → cbtxt
// picList font14   → shuxiangdzs
// picList font16   → nmxswz
// "col-12 col-md-6"→ x630
// imglist          → imglist369
// <div class="list"> → div.list（需进一步区分 fanqxsw / dadawx）
```

**div.list 二分法**：fanqxsw 是"图文卡片"（picb+txtb+about+intro+time），dadawx 是"表格行"（ul 首行是表头 li 分类/书名/最新章节/作者）。抽查一个 `<li>` 逐字段核对模板选择器：

```html
<!-- xiakezww 实测：与 fanqxsw 模板逐字段吻合 -->
<li>
  <div class="picb"><div class="pic"><a href="/book/6314531.html"><img src="..."/></a></div></div>
  <div class="txtb">
    <div class="name font24"><a href="/book/6314531.html">书名</a></div>
    <div class="about"><span></span><span>连载</span><span>19.08万字</span></div>
    <div class="intro">...</div>
    <div class="time"><span>作者</span> <span>时间 更新</span></div>
  </div>
</li>
```

## 第 2 步：书籍页四项检查

```javascript
var p = String(java.get(host + "/book/6314531.html", H).body());
// ① bookId（注意 SEO URL 与真实 id 可能不同，og:url 才准）
p.match(/content=".*\/book\/(.*?)\.html"/)[1]   // → "6314531"
// ② AES 密钥（遍历所有模板JS，首个可能无密钥）
/src="(\/templates\/js\/[a-zA-Z0-9]{1,}\.js)"/g 逐个下载找 /AESCrypt\('/
// ③ og:novel 元标签（详情规则通用前提）
/og:novel:book_name|og:novel:author|og:novel:latest_chapter_name/
// ④ 正文容器
章节页 /book/ID-1.html 检查 .content / <article> / #ad
```

xiakezww 实测：bookId✓ 密钥✓(uFxZq6PpL9pzsIItj0MFpSQfdWcFIvWu.js) og✓ `.content`✓ → 零改动接入。

## 第 3 步：加映射 + 全链路调试

```javascript
// HOST_TEMPLATE_MAP 加一行
'https://www.xiakezww.com': 'fanqxsw',
```

```
debug_source 关键词"系统"（checkKeyWord），核对：
[搜索]  列表大小:20，详情页链接为真实域名
[详情]  bookId/密钥来源/书名/作者/分类/最新章节/简介
[目录]  列表大小:333（4页加密接口合并）
[正文]  首章内容完整无漏字
```

## 第 4 步：异常分支处理

| 检查失败项 | 处理 |
|-----------|------|
| 列表结构无匹配模板 | 新建 TEMPLATES 条目 + 映射 |
| 首个 JS 无密钥 | 确认 init 的遍历逻辑（已内置） |
| 正文容器是 article/#ad | 已有三容器兜底，无需改 |
| POST 被WAF拦 | 已有防WAF头，确认生效 |
| og:novel 缺失 | 详情规则加域名分支 |
