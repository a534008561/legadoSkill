# 补充-禁漫天堂 v2.4：发现页增加标签筛选

> 261128 用户要求「发现增加标签筛选」。成品 `examples/禁漫天堂_jmtt_v2.4_标签筛选.json`。

## 站点契约

- `/{seg}/tags` 是标签总页，条目形如 `<a class="jm-tagwall__tag" data-tag-name="制服" href="/novel/tag/%E5%88%B6%E6%9C%8D">`；列表页筛选栏的 tag 行也给热门标签。
- 实测数量：comic 20、novel 20、mv 192、drama 0（drama 用 `/drama/all` 筛选栏的 5 个标签）。
- `/{seg}/tag/{encoded}` 是独立列表页，**支持 `?status=`/`length=`/`subtitle=`/`duration=` 查询筛选**，分页是 `/{seg}/tag/{encoded}/2`。
- ★**标签不能与分类路径叠加**：`/novel/all/dsjq?tag=制服` 实测 sum 仍显示「都市激情·全部」，tag 被忽略；非默认排序同样会丢分类。

## 发现页改动

- 每类新增 `{类型}标签` **下拉 select**（小说标签/视频标签/漫画标签/短剧标签），选项 = 全部 + 站点真实标签（mv 取前 40 个，其余全量），值烘焙进入口 URL；action 仍 `java.refreshExplore()`。
- 选中某标签后：分类直入口隐藏，改为一条 `🏷 {类型}·标签：{tag}（标签与分类不可同时）` URL 入口 → `{{jmHost(source)}}/{seg}/tag/{encoded}{{page>1?('/'+page):''}}?筛选参数`；榜单入口保留。
- 标签=全部时恢复原分类直入口 + 榜单。

## 验证

- qjs：小说默认 25 行（5 控件 + 16 分类 + 4 榜单）；小说选「制服」10 行（5 控件 + 标签入口 + 4 榜单）；视频选「巨乳」10 行。
- MCP `debug_source ::{{jmHost(source)}}/mv/tag/%E5%8F%A3%E4%BA%A4{{page>1?('/'+page):''}}`：列表 20 条、详情/目录/正文全绿，正文仍是 v2.3 的 `data:/stream.m3u8?;base64,...`（视频修复未回归）。
