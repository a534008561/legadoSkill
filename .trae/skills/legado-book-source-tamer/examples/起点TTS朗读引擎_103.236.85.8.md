## 使用

1. 导入 `起点TTS_朗读引擎6个.json`：朗读引擎 → 右上角菜单 → 本地导入（支持 JSON 数组）
2. 音色切换按钮：主引擎 → 编辑 → ⋮ 菜单 → 登录 → 点音色按钮，返回小说直接朗读生效
3. 语速：阅读界面朗读菜单滑杆（显示 1.0 = 站点 50 正常语速）

## 关键技术点（详见配套文档第 4~6 节）

- url 用 `<js>` 整段 + `JSON.stringify(bd)` 拼 body —— 正文含英文引号/换行/反斜杠不会炸 JSON
- 音色/语速模式存 `source.put/get`（BaseSource→CacheManager），未设置时规则内兜底 `ifly/4001/std`，刚导入即可用
- `loginCheckJs` 拦截 <800 字节的 `detail`/`<html`/`<!doctype` 响应并 throw 中文报错（防 4xx 被当音频播放成"无声"），兼容 body 属性/方法两种 App
- 「🔊 连通测试」按钮现场合成一句并回报字节数/耗时，是排查"没声音"的第一入口
