## 一、总体架构：五段 URL + 双层密钥

| 环节 | 接口 | 域名 | 请求方式 | 加密情况 |
|------|------|------|----------|----------|
| 搜索 | `/androidapi/search` | `app.jjwxc.org` | GET | 无 |
| 详情 | `/androidapi/novelbasicinfo` | `app-cdn.jjwxc.net` | GET | 无 |
| 目录 | `/androidapi/chapterList` | `android.jjwxc.net` | GET | 无（需 token 看 VIP 章） |
| 正文 | `/androidapi/chapterContent` | `app.jjwxc.org` | GET | **第一层**：响应头派生密钥；**第二层**：content 字段 DES |
| 购买 | `/androidapi/buy` | `android.jjwxc.net` | GET（query） | URL 参数签名 |

### 1.1 关键设计：`bookUrlPattern` 的强制一致性

```json
"bookUrlPattern": "https?://app-cdn\\.jjwxc\\.net/androidapi/novelbasicinfo\\?novelId=\\d+"
```

**价值**：Legado 内部大量缓存以 `bookUrl` 为 key。如果搜索页/发现页/目录页的 `bookUrl` 不统一，旧缓存章节链接全部失效。
**经验**：
- 如果站点的"详情"接口统一用 `app-cdn.jjwxc.net/androidapi/novelbasicinfo?novelId=X`，所有入口的 `bookUrl` 模板必须一致。
- `ruleSearch.bookUrl`、`ruleExplore.bookUrl` 两条都要对齐，差一个域名全乱。

## 二、加密与解密：双层密钥系统（核心难点）

### 2.1 第一层：固定密钥 DES/CBC 加密

```js
// jsLib
function encode(data){
    return java.createSymmetricCrypto("DES/CBC/PKCS5Padding", "KW8Dvm2N", "1ae2c94b").encryptBase64(data)
}
```

- 算法：`DES/CBC/PKCS5Padding`（8 字节 key + 8 字节 IV）
- key = `"KW8Dvm2N"`
- iv = `"1ae2c94b"`
- 输出：Base64

**破解关键**：晋江 APK 用 JEB/jadx 反编译后 `encrypt/decrypt` 调用点附近必然有这两个字符串。
**复用方法**（任何疑似 DES/CBC 的书源）：
```js
function decryptContent(b64, key, iv){
    return String(java.createSymmetricCrypto("DES/CBC/PKCS5Padding", key, iv).decryptStr(b64))
}
```

### 2.2 第二层：响应头动态派生密钥（VIP 章节）

> 这是**整篇文档最值得复用的技巧**。

VIP 章节的响应**不是** JSON，而是一段密文，密钥**由响应头派生**：

```
响应头: accesskey: AAAA...BBBB
响应头: keystring: xxxx
响应体: <密文 base64>  (去前/后12字节得到 dest + v38)
```

**派生算法**（从晋江 APK 反编译的 Smali 翻译成 JS）：

```js
function decryptVipRaw(rawBody, ak, ks) {
    if (!ak || !ks || !rawBody) return "";
    var v6 = ak.charCodeAt(ak.length - 1);                 // 末位 char 码
    var v9 = 0;
    for (var i = 0; i < ak.length; i++) v9 += ak.charCodeAt(i);  // 累加和
    var v15 = v9 % ks.length;                              // keystring 切片起点
    var v17 = Math.floor(v9 / 65);                         // 切片长度
    var v43 = ks.substring(v15, (v17 + v15 > ks.length) ? ks.length : (v17 + v15));

    var v38, dest;
    if ((v6 & 1) !== 0) {
        v38 = rawBody.slice(-12);   // 末位奇数：密文尾 12 字节是 v38
        dest = rawBody.slice(0, -12);
    } else {
        v38 = rawBody.slice(0, 12); // 末位偶数：密文头 12 字节是 v38
        dest = rawBody.slice(12);
    }
    var key = String(java.md5Encode(v43 + v38)).slice(0, 8);
    var iv  = String(java.md5Encode(v38)).slice(0, 8);
    return String(java.createSymmetricCrypto("DES/CBC/PKCS5Padding", key, iv).decryptStr(dest));
}
```

**关键技巧 — 如何判断当前是密文响应？**：

```js
function isRawCipher(b) {
    return b && b.length > 60 
        && !/^\s*\{/.test(b)                        // 不是 JSON
        && b.indexOf('"content"') < 0               // 也没有 content 字段
        && b.indexOf('"message"') < 0
        && b.indexOf('"code"') < 0;
}
```

**Legado API 坑**：标准 okhttp 响应拿不到响应头，必须用 `java.get(url, {}).header("accesskey")`！

```js
// ❌ 这样拿不到 header
var r = String(java.ajax(url));
// ✅ 用 java.get 拿 ResponseDoc
var resp = java.get(url, {});
var raw = String(resp.body());
var ak = String(resp.header("accesskey"));
```

## 三、登录体系：账密+扫码+设备验证自动重试

### 3.1 三种登录失败码的语义

| 错误码 | 含义 | 处理 |
|--------|------|------|
| 200 / 有 `token` | 登录成功 | 持久化 token |
| `6018` / `221003` | 服务端要求设备验证 | 自动追加 `checktype=phone/email + checkdevicecode=<任意>` 重试 |
| `1004` / "登入验证失败" | 账号或密码错误 | 终止，提示用户 |

### 3.2 自动重试模板（核心 7 行）

```js
function doLoginOnce(account, password, checktype, code){
    var en = encode(password);
    var now = String(Date.now());
    var id = ("846"+now+"4893")+":"+java.androidId()+"d4:";
    var sign = encode(now+"_"+id+"_");
    var url = "https://.../login?loginName="+encodeURIComponent(account)
        +"&encode=1&loginPassword="+encodeURIComponent(en)
        +"&sign="+encodeURIComponent(sign)
        +"&identifiers="+encodeURIComponent(id)+"&autologin=1";
    if (checktype && code) {
        url += "&checktype="+checktype+"&checkdevicecode="+encodeURIComponent(code);
    }
    var r = String(java.ajax(url));
    try { return JSON.parse(r); } catch(e){ return {"code":"-1","message":r.slice(0,120)}; }
}
```

**登录流程设计**：
```
1. 裸登录 → 失败
2. 追加 checktype=phone + checkdevicecode=<code or "000000"> → 失败
3. 换 checktype=email + checkdevicecode → 失败
4. 报"请尝试扫码登录"
```

**核心发现**：晋江 getDeviceSecurityCode 验证码下发接口**对无 App 签名请求一律拒绝**（2021 起）。
→ 书源内**完全无法**走真实验证码流程，必须**用 `checktype+checkdevicecode` 绕过**。
→ 实测假码 `"000000"` 就能通过（服务端不验内容只验存在性）。

### 3.4 登录头持久化（取代 cookie 的另一种方式）

```js
// jsLib 工具集
function getHeaderMap(_){
    let infomap = String(source.getLoginHeader()).replace(/^#/,'');
    infomap = (infomap!="null"&&infomap!=""&&infomap!=null) ? infomap : "{}";
    return JSON.parse(infomap);
}
function setHeaders(){
    let map = getHeaderMap(this);
    for (let i=0; i<arguments.length; i++){
        let k = arguments[i].split("=")[0];
        let v = arguments[i].split("=")[1];
        map[k] = v;
    }
    source.putLoginHeader("#"+JSON.stringify(map));  // 关键：用 # 前缀占位空值
}
```

**为什么用 `#` 前缀**？
→ Legado `source.getLoginHeader()` 返回空字符串时无法直接 JSON.parse
→ 用 `#{}` 占位 → `.replace(/^#/, '')` 还原 → 既能存空值又能存对象

**两种读取方式**（晋江发现 Rhino 框架和 Jetpack 框架差异）：
```js
// ✅ 通用
var token = String(source.getLoginHeaderMap().get("token") || "");
// 旧 Rhino 框架
var map = JSON.parse(String(source.getLoginHeader()).replace(/^#/,''));
var token = map["token"];
```


## 七、自定义付费流程：`payAction`

```js
// ruleContent.payAction
baseUrl = bDe(baseUrl);                                  // 1. 解析出真实参数
cid = baseUrl.match(/chapterId=(\d+)/)[1];
nid = baseUrl.match(/novelId=(\d+)/)[1];
token = Map("token");
if (!/^\d+_[\w\d]{16,}/.test(token)) {
    java.longToast("❌ 尚未登录…");
    result = false;                                       // 2. 未登录直接拒
} else {
    // ---- 3. 余额预查（失败不阻断）----
    try {
        var bSign = encode(String(Date.now())+":"+token);
        var bUrl = "https://.../getUserBalance?...&sign="+encodeURIComponent(bSign);
        var bJson = JSON.parse(String(java.ajax(bUrl)));
        var bal = bJson.balance ?? bJson.data?.balance;
        if (bal !== undefined) balMsg = "💰 当前余额："+bal+" 晋江币\n";
    } catch(eb){ java.log("balance check error: "+eb); }

    // ---- 4. 签名 + 购买 ----
    enbody = String(Date.now())+":"+token+":"+nid;
    sign = encode(enbody);
    q = "versionCode=381&novelId="+nid+"&chapters="+cid+"&orderType=15&isautoBuy=0&sign="+encodeURIComponent(sign);
    url = "https://android.jjwxc.net/androidapi/buy?"+q;
    a = String(java.ajax(url));
    var r = JSON.parse(a);
    if (/购买成功/.test(r.message)) {
        java.longToast("✅ "+r.message+"\n"+balMsg);
        result = true;     // ⭐ 关键：返回 true 触发自动重载章节
    } else if (r.code == "1004") {
        java.longToast("❌ 登录已过期…");
        result = false;
    } else if (/余额/.test(r.message)) {
        java.longToast("❌ "+balMsg+r.message);
        result = false;
    }
}
```

**payAction 三件套**：
1. **余额预查** — 失败不阻断（避免余额接口故障影响购买）
2. **签名请求** — 关键参数 = `Date.now() + ":" + token + ":" + novelId`，DES 加密
3. **`result = true`** — 触发 Legado 自动重抓当前章节（**这是购买后自动解锁的关键**）

**实战坑**：
- buy 接口**只解析 URL 查询串**，POST body 会被忽略
- 错误码 `1004` 频繁出现（token 1 小时过期），必须有清晰重登提示
- `r.popupdata.popupmessage` 偶尔出现（防沉迷/优惠券弹窗），需要兜底显示

## 十二、避坑清单（实战总结）

| 坑 | 现象 | 解决 |
|----|------|------|
| `data:` URL 当章节 URL | Legado okhttp 拒绝 | 用真实 HTTP URL |
| 设备验证接口不可用 | `getDeviceSecurityCode` 永远 1004 | 走 `checktype+checkdevicecode` 绕过 |
| `preUpdateJs` 不写 | 旧缓存的目录仍带过期 token | 必写，失败时 `java.refreshTocUrl()` |
| 余额预查失败阻断购买 | 余额接口偶尔超时 → 买不了 | try/catch 包住，失败不 return |
| buy 接口用 POST body | 服务端忽略 body | 必须把参数全塞 URL 查询串 |
| `source.getLoginHeaderMap()` 在 Rhino 框架报错 | 旧版阅读不识别 | 改用 `String(source.getLoginHeader())` + JSON 解析 |
| `java.ajax` 不返回 Response 对象 | 拿不到 header | 用 `java.get(url, {})` 替代 |
| `cache.put` 不设过期 | 永久缓存旧 token | 必须传 seconds |
| `startBrowserAwait` 不等用户扫码就轮询 | 拿不到 token | 第三个参数 `false` = 不显示工具栏，返回值就是 body |
| bookUrl 多入口不一致 | 搜索/发现缓存冲突 | 强制统一 `bookUrlPattern` |
| 详情页 `novelCover` 没 referer | 图片 403 | `result.match(/(^https?:\/\/.*?\/)/)[1]` 提取加 referer |
| VIP 已购章节响应是密文 | decrypt 失败 | 三态分流：JSON正常/JSON错误/纯密文 |
| `ruleExplore.bookList` 不加 `$[*]` | JSON 数组当字符串 | **必须以 `$[*]` 结尾** |
| 登录密码明文存 | 安全风险 | DES 加密后再存 (`encode()`) |
