# 方法：正文跨页「重复输出整章」识别与整页去重

> 来源：桔纸书屋 m.juzhishuwu.net 书源（2026-10-23，全程在阅读 App 内经 MCP 实测）
> 关联：[[方法-正文跨页断字修复与逐行广告过滤]]（同一类站点的另一种病）

## 0. 一句话结论

分页站点的正文异常不止「句子被切断」一种。**更阴险的一种是：站点把整章正文重复输出 N 份**，
每份之间夹着一条「< "https:">提供的《书名》 第X章 XXX(第N页)」标记。
若只按 `<br>` 切行 + 过滤广告，会得到 **5 倍长度的正文**，而且看起来"每段都通顺"，极难察觉。

**判据**：正文容器里 `提供的《` 或 `(第\d+/\d+页)` 这类标记出现 ≥2 次 → 站点重复输出。
**处置**：切行时**遇到第 2 个分页标记就 break**，只保留第 1 份。

## 1. 现象

同一章 `https://m.juzhishuwu.net/xs/440465935/46987112.html`，`#content` 原始 HTML 长度 7943，
切行后 85 行，结构如下（节选）：

```
0:  < "https:">提供的《完美世界》 序章 大荒(第1/1页)
1:  夜已深，漆黑一片，景物不可见。…
...
16: 一根散发着莹莹绿霞的柔弱柳条在风中轻轻摇曳
17: 【请收藏，wjiwenxue.com 努力为你分享更多好看的小说】
18: </div>< "https:">提供的《完美世界》 序章 大荒        ← 第 2 份开始
19: 夜已深，漆黑一片，景物不可见。…                        ← 与第 1 行重复
...
36: 【请收藏，wjiwenxue.com 努力为你分享更多好看的小说】
37: </div>< "https:">提供的《完美世界》 序章 大荒        ← 第 3 份
...
54: ...                                                  ← 第 4 份
...
73: ...                                                  ← 第 5 份
```

站点把同一章拼了 **5 份**，每份前面挂一条 `</div>< "https:">提供的《…》(第N页)`。

### 1.1 为什么会这样

这类杰奇CMS 模板站，正文分页时不是「每页返回该页内容」，而是：

- `xxx.html` = 第 1 页内容 + **（误拼）后续所有页的完整副本**
- `xxx_2.html` = 第 2 页内容（正常）

即**第 1 页就已经把整章塞进去了**，`a.btn-info` 指向 `_2.html` 是模板残留。
所以跟着 `a.btn-info` 再抓第 2 页，等于把尾部又拼一遍。

### 1.2 为什么「过滤广告行」救不了

广告过滤是按行删噪声，删掉标记行之后，**重复的正文段落仍然全在**：

```
85 行 → 过滤广告后仍是 74 行（正文重复 4 次）
```

且每段都通顺、没有特征词，任何关键词黑名单都命中不了。

## 2. 两个互补的判据（都要有）

### 2.1 判据 A：遇到第 2 个分页标记就截断（页内重复）

```js
var MARK=/提供的《|\(第\d+\/\d+页\)|^<\/div>|^&lt;\s*"https:/;
// 切行循环里：
if (MARK.test(t) && arr.length > 0) break;   // 第一行标记允许（arr 为空），第二个标记直接停
arr.push(t);
```

要点：

- `arr.length > 0` 这个条件必须有 —— 第 1 份的标记行是**首行**，要跳过但不能 break。
- 标记要覆盖 **HTML 实体形式**：jsoup 的 `Element.html()` 会把 `<` `>` 转义成 `&lt;` `&gt;`，
  所以真实字符串是 `&lt; "https:"&gt;提供的《…》`，正则里得写 `^&lt;\s*"https:` 才能命中。
- `^<\/div>` 兜住「上一份的闭合标签被当正文」的情况。

### 2.2 判据 B：整页与已收内容重复则跳过（跨页重复）

有些书是「第 1 页正常、第 2 页是第 1 页的尾部重复」（实测《完美世界》序章：
`_2.html` 开头 `路过石村…` 正好是第 1 页第 10 行）。
只做判据 A 不够 —— 第 2 页开头没有标记，会正常拼进去。

```js
function isRepeat(page,out){
  if(out.length<3||page.length<2) return false;
  var p0=page[0], lo=Math.max(0,out.length-60);
  for(var i=lo;i<out.length;i++){
    if(out[i]!==p0) continue;
    var ok=0;
    for(var j=0;j<page.length&&i+j<out.length;j++){
      if(out[i+j]!==page[j]) break;
      ok++;
    }
    if(ok>=Math.min(3,page.length)) return true;   // 连续 3 段一致即判重
  }
  return false;
}
```

- 只回溯最近 60 段（`out.length-60`）—— 章节可能几百段，全量扫是 O(n²)。
- 连续 **3 段**一致才判重 —— 只比 1 段会误杀「”好。“」这类高频短句。
- `Math.min(3,page.length)` —— 尾页可能只剩 1~2 段。

## 3. 完整正文规则（含两套判据）

```js
@js:(function(){
  var J=Packages.org.jsoup.Jsoup;
  var MARK=/提供的《|\(第\d+\/\d+页\)|^<\/div>|^&lt;\s*"https:/;
  function segs(h){
    var d=J.parse(h), box=d.select('#content').first();
    if(box==null) return null;
    var c=box.clone(); c.select('a,script,style').remove();
    var parts=String(c.html()).split(/<br\s*\/?>/i), arr=[];
    for(var i=0;i<parts.length;i++){
      var t=parts[i].replace(/<[^>]+>/g,'').replace(/^[ \t\r\n]+/,'').replace(/[ \t\r\n]+$/,'');
      if(t.replace(/&nbsp;|&amp;|\s/g,'')==='') continue;
      if(MARK.test(t)&&arr.length>0) break;          // ★判据A
      arr.push(t);
    }
    return {arr:arr, next:(box.select('a.btn-info').size()>0?box.select('a.btn-info').attr('href'):null)};
  }
  function isRepeat(page,out){ /* 见 §2.2 */ }
  var cur=segs(result), out=[], guard=0;

         .replace(/&quot;/g,'"').replace(/&#39;/g,"'").replace(/&amp;/g,'&');
```

## 4. 本站广告行清单（实测 8 本 × 3 章，去重后）

| 广告原文 | 形态 | 覆盖写法 |
|---|---|---|
| `你现在阅读的是< "https:" >` | 裸 `https:`，**没有 `//`** | `DOM=/https?:\/\/\|https?:\s*"\|…/` |
| `< "https:">提供的《书名》 第X章 XXX(第N页)` | 分页标记 | 判据 A 已截断 |
| `【请收藏，wjiwenxue.com 努力为你分享更多好看的小说】` | 方括号 + 域名 | `请收藏` + `wjiwenxue` |
| `恋上你看书网 630bookla ，最快更新万古神帝最新章节！` | **他站站名**（盗转源） | `恋上你看书|bookla|最快更新` |
| `作者有话要说　　挖新坑了，努力填土，明天见` | 作者话，**不是广告** | ⚠ 必须保留 |
| `【首发起点读书，请支持正版阅读】` | 正版提示 | `首发起点|支持正版` |
| `您现在阅读的是《正道魁首是如何养成的》1、【第1章】外门弟子` | 他站标题行 | `您现在阅读的是` |
| `看清爽的小说就到` | 半句（后面域名被吃） | `看清爽的小说就到` |

**关键：`< "https:" >` 没有 `//`**。
第一版 `DOM=/https?:\/\//` 完全漏掉它，因为字符串是 `https:` + 空格 + `"`。
正确写法：`/https?:\/\/|https?:\s*"|www\.|\.com|\.net|\.org|bookla|提供的《/`。

## 6. 排查顺序

1. `java.ajax(chapterUrl)` → `J.parse` → `select('#content').first()` → `clone()` → 去掉 `a,script,style`
2. 打印 `String(c.html()).slice(0,300)` 看首行
3. 统计 `提供的《` 与 `(第\d+/\d+页)` 出现次数
   - ≥2 → 站点重复输出，走判据 A
4. 若第 1 页正常，再抓 `_2.html`，比对 `_2` 首段是否已出现在第 1 页末尾 → 走判据 B
5. 两条都加，再用 6 本书跑一遍，统计「残留噪声行数」必须为 0

## 7. 适用站点特征

- 正文 URL 形如 `xxx.html` / `xxx_2.html`
- `h1` 里写着 `(第1页/共2页)`
- `a.btn-info` 文案含「本章未完，点击下一页继续阅读」
- 正文首行有 `< "https:">提供的《书名》…(第N页)`
- **正文异常地长**（一章 5000+ 字变 2 万字）
