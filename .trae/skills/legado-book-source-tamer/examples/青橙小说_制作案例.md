## 签名协议（详见经验文档）
```
_s   = MD5(deviceId+userId) 固定
sign = HMAC-SHA256(KEY="NiozHhg/lMm5ja-DVEV_jzk$,t0B4*$5",
                   path+encodedQuery+"&"+R0+"&"+排序POST参数(解一层URL编码))
_p   = URLEncode(Base64(DES/ECB/NoPadding(DESK="snY%169j", R0+"&sign="+sign + \u0001填充)))
```
`R0` 与 `time` 冻结为一张官方票据（实测 40 分钟后仍 `code=0`，服务端无时间窗口/重放防护）。
