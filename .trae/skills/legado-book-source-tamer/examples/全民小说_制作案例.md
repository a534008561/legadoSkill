- 成品：`/workspace/quanmin/全民小说_v1.json`（46KB），阅读书源名 `📖 全民小说`，`bookSourceUrl=https://book.yutinglu.com`。
- APK：`全民小说5.0.8（免登会员）.apk`，包名 `com.qmxsppa.novelreader`，版本号 5.0.8；抓包业务头里 `version=5.0.5 / channel=new2025`。
- 用户要求：发现规则、书源 URL 正则、设置 UA、ProxyPin + MT MCP、LAN 保存大文件、登录 UI、发布页输入框/一键取网址/测速 ms 回填/逐网址切换/全阶段 Toast、不主动探测搜索频率、兼容 LT 与 legado-E。
- 用户追加：「发现和顶点小说很像，全量参考顶点小说书源」→ 以阅读里 `🐈 猫眼看书 v5.4`（顶点小说 App 的 yutinglu 协议源）为全量内核；登录面板参考 `🐾顶点小说xsbook` 的发布页线路管理范式。

## 关键证据

- ProxyPin：16:15 广告控制页 `bqm.125ks.cn/jc/*.php`，16:18 业务流 `book/catalog/chapter.yutinglu.com`，请求头明确 `com.qmxsppa.novelreader`；
- MT MCP：打开 APK 读 `assets/info.json` 得广告控制页配置；`com.share.sdk.entity.ApiInfo` 只有 `request_url/sub_bundle`；`com.tencent.as.javask` 加载 `request_url + /jc/v.php` ⇒ 证明该域不是小说 API；
- 对照请求：旧包名头 / 全民小说头对 `book_city` 都 200 + `code:1`；`conf` 对两个包名都 200；
- 完整经验：[references/方法-同后端套壳App书源复用与双版本安全改造.md](references/方法-同后端套壳App书源复用与双版本安全改造.md)。
