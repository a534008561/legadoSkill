## 三十余个版本换来的四句话

1. **正文语种由「铸 key 那次请求的 Cookie」决定**（`transmode=chinese`），
   不是读正文时带的 Cookie；抄错一次，后面 degloss / squeeze / 分段 / 排版全在擦屁股。
2. **中文目录在响应的 `oridata` 字段**，`data` 是越南语；只读自己预期的字段会得出完全错误的结论。
3. **正文「一整段」有三个关口**：规则输出 → 净化链路（这个 App 比上游激进，会把段落合并）
   → 渲染层（TextView 不给 `<p>` 间距，只有 `<br/>` 换行）。修「怎么切」是没用的。
4. **站点编号会跳号、会有无编号条目**（上架感言之类）。书源的职责是「与官方 App 显示一致」，
   不是「自行修正编号」——任何「跳过重复/要求递增」的清洗都会产生累积偏移。

## 已实现的能力

- 正文稳定中文（`transmode=chinese` 铸会话；对照版有 `<i t='中文'>` 兜底还原）
- 目录中文章名（`oridata` 跨来源对译）+ 🔑/🔒 双态解锁标记（与服务端 `unvip` 计数交叉校验）
- 章节 ID 用真编号（`序号+雪花ID` 混合，按「紧邻章名左槽、更长者优先」解析，`#s=` 片段备用）
- 分段自适应（站点结构优先，无结构才走五切法打分）
- 自动换源（死源→活源，跨来源用越南语章名定位；可在登录面板开关）
- 登录面板（账密 + Cookie 粘贴 + 状态检查 + 退出 + 自动换源开关），线路切换带自检
- 详情页来源列表（可换源保进度）
