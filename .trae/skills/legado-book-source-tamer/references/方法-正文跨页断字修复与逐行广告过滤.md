# 方法：正文跨页断字修复与逐行广告过滤

> 来源：爱看书吧 m.2tsw.com 书源（2026-10-23，全程在阅读 App 内经 MCP 实测）

## 一、问题现象

某些 GBK 老站点（杰奇CMS 系）在正文分页处**不做任何缓冲，直接按字节截断 HTML**，导致：

### 1. 句子被拆开

```
第 1 页末尾：……这……周明
第 2 页开头：瑞顿时倒吸了口凉气
```

拼起来变成两段，读者看到「这……周明 / 瑞顿时倒吸了口凉气」。

### 2. HTML 实体被切成两半

`&nbsp;` 被从中间切开：

```
第 1 页末尾：&amp;n     ← &nbsp; 的前半截
第 2 页开头：bsp;        ← &nbsp; 的后半截
```

用 `nextContentUrl` 逐页取再 `joinToString("\n")`，会得到：

```
　　洪荒世界。
　　&amp;n
　　bsp;那可是充满着传奇的一个世界。
```

### 3. 广告行夹在分页边界

分页处往往同时插入广告，进一步干扰拼接判断。

## 二、为什么常规写法救不了

| 写法 | 结果 |
|---|---|
| `nextContentUrl` + `##广告正则` | 只能替换**单个**正则，无法同时处理断字 + 多类广告；且 `replaceRegex` 字段会被当作 CSS 规则解析，不能直接写正则 |
| `content` 用 `id.content@html` | 拿到的是单页，断字仍在 |
| `##match##replace` | 无法跨页 |

**结论：必须在 `@js` 里自己控制抓页循环和拼接。**

## 三、正确方案（实测可用）

```js
@js:var u=baseUrl,ps=[],g=0;
function isAd(t){...}
while(u&&g<30){
  g++;
  var d=org.jsoup.Jsoup.parse(String(java.ajax(u)));
  var c=String(d.select('div#content').html());
  // 1) 整块删除按钮与干扰标签（连前面的 <br> 一起删）
  c=c.replace(/(?:<br\s*\/?>\s*)*<a[^>]*btn-addbs[^>]*>[\s\S]*?<\/a>/g,'')
     .replace(/(?:<br\s*\/?>\s*)*<a[^>]*btn-info[^>]*>[\s\S]*?<\/a>/g,'')
     .replace(/(?:<br\s*\/?>\s*)*<font[^>]*>[\s\S]*?<\/font>/g,'');
  // 2) 按 <br> 切行，逐行判定广告
  var a=c.split(/<br\s*\/?>/i),k=[];
  for(var i=0;i<a.length;i++){
    var r=a[i];
    var t=r.replace(/<[^>]*>/g,'').replace(/&nbsp;/g,' ').trim();
    if(t!==''){ if(isAd(t))continue; if(/^[(（]?\s*第\s*\d+\s*[\/／]\s*\d+\s*页\s*[)）]?$/.test(t))continue; }
    k.push(r);
  }
  // 3) ★关键★ 每页剥掉首尾空白与 <br>，才能无缝拼接
  ps.push(k.join('<br>')
    .replace(/^(?:\s|<br\s*\/?>)+/i,'')
    .replace(/(?:\s|<br\s*\/?>)+$/i,''));
  var b=d.select('a.btn-info');
  u=b.size()>0?String(b.get(0).attr('href')):null;
  if(u==='')u=null;
}
// 4) 跨页断裂实体修复
var s=ps.join('')
  .replace(/&(?:amp;)?n\s*bsp;/g,'&nbsp;')
  .replace(/&(?:amp;)?n$/g,'')
  .replace(/^\s*bsp;/g,'');
s
```

### 三个要点

1. **`ps.join('')` 而不是 `join('\n')`** —— 页面之间不能加换行，否则句子还是断的。
2. **每页首尾必须剥 `<br>`** —— 站点在截断处残留的 `<br>` 会被格式化器变成换行。
3. **实体修复放最后** —— 先拼接再修复，`&n` 和 `bsp;` 才在同一字符串里。

## 四、逐行广告过滤（附反向验证）

### 三层判定函数

```js
function isAd(t){
  if(!t) return false;
  // ① 整行仅是「无广告/广告」噪声（允许包裹标点）
  if(/^[\s.。!！·~～\-—、,，]*[（(【\[]?(?:无广告|广告)[）)】\]]?[\s.。!！·~～\-—、,，]*$/.test(t)) return true;
  // ② 域名 + 站点话术同时出现（避免误伤正文里提到的网址）
  if(/(?:[a-z0-9-]+\.)+(?:com|net|org|cc|la|info|vip|xyz|top|cn|me|tv|co)\b/i.test(t)
     && /收藏|访问|网址|更新|首发|记住|小说|最新章节|请到|来自|网/.test(t)) return true;
  // ③ 固定广告语黑名单
  if(/这章没有结束|请点击下一页继续阅读|请大家收藏|更新速度全网最快|首发域名|请记住本站|最新网址|请收藏本站|提供的《|本章未完|wjiwenxue/.test(t)) return true;
  return false;
}
```

### ★反向验证（必做）★

| 样本 | 期望 | 结果 |
|---|---|---|
| `他在广告公司上班，每天加班到深夜。` | KEEP | KEEP |
| `无广告的阅读体验确实舒服很多，可惜这样的站点太少了。` | KEEP | KEEP |
| `我在 www.example.com 上看到过这个。` | KEEP | KEEP |
| `他打开电脑，输入了 google.com，页面跳了出来。` | KEEP | KEEP |
| `..！无广告！` | DROP | DROP |
| `（无广告）` | DROP | DROP |
| `这章没有结束，请点击下一页继续阅读！` | DROP | DROP |
| `喜欢…请大家收藏：xxx.bayizww.com网更新速度全网最快。` | DROP | DROP |
| `< "https:">提供的《诡秘之主》 第一章 绯红(第1/2页)` | DROP | DROP |
| `更多精彩小说请访问 www.abc.com` | DROP | DROP |

**关键教训**：第一版用 `/无广告/` 裸匹配，把「无广告的阅读体验确实舒服很多」这种正文也删了。必须写成「整行仅是噪声」的锚定正则。

## 五、实测广告变体清单（同模板站点通用）

| 广告原文 | 位置 |
|---|---|
| `< "https:">提供的《书名》 第X章 XXX(第1/2页)` | 分页首行 |
| `本章未完，请点击下一页继续阅读` | 分页末尾 |
| `这章没有结束，请点击下一页阅读！` | 分页末尾 |
| `喜欢《书名》请大家收藏：xxx.com网更新速度全网最快。` | 分页末尾 |
| `【请收藏，wjiwenxue.com 努力为你分享更多好看的小说】` | 分页末尾 |
| `..！无广告！` | 正文首行 |
| `(第1/2页)` / `（第2/2页）` 独立成行 | 分页边界 |

## 六、适用站点特征

命中以下任一特征就该考虑本方案：

- 正文分页 URL 形如 `xxx_2.html`、`xxx_2.html`（同一章多文件）
- 页面上有 `a.btn-info` 之类「本章未完，点击下一页」按钮
- 阅读时发现句子在两页交界处断开
- 正文里出现 `&n`、`bsp;`、`&amp;n` 等残缺实体
- 每页正文首尾都有固定广告语

## 七、代价与风险

1. `@js` 正文规则**不会走 `nextContentUrl`**，需自己循环（建议设 `g<30` 上限防死循环）。
2. 每页都要 `java.ajax`，比原生分页多一层 JS 开销；实测 2 页章节约 0.2 秒。
3. `java.ajax` 会走书源的 `concurrentRate` 限频，若站点限频严需注意。
4. 站点改版（class 名、按钮名变化）会导致整段失效，需重新抓页面确认。
