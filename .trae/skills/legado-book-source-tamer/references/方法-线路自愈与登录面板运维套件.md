# 方法-线路自愈与登录面板运维套件（八叉书库实战）

> 适用场景：**多域名轮换站**（成人站/盗版站/发布页站最常见），主域经常被封，需要用「发布页 + 测速选线 + 一键切换」让书源自己活下去。
> 蓝本：`🌈八叉书库`（bookSourceUrl=https://八叉书库.luoyacheng.ip-ddns.com），站点 8xsk.cc 家族，35 个面板按钮，5 个备用域名。
> 本文件只讲**线路层与面板层**；正文/目录/下载等规则细节见同目录其它文档。

---

## 0 一句话总结

**站点域名会死，书源不能死** —— 把「域名」变成书源变量（而非写死在规则里），再给用户三个按钮：
`🚀一键测速选站`（自动挑最快）、`💍从发布页取址`（域名全死时的最后出路）、`🌐站点快切`（手动指定），
配合 `getsurl()` 单点读取，全站规则自动跟随。**改一处，全站生效。**

---

## 1 为什么必须做（真实故障谱系）

| 症状 | 根因 | 用户感受 |
|---|---|---|
| 搜索/发现全部报错 | 主域 DNS 失效 / 被墙 | 「书源坏了」 |
| 部分功能能用部分不能 | 硬编码域名的规则漏改 | 「有时能用有时不能」 |
| 换域名后书架书全空 | 书籍 URL 存的是旧域名 | 「我的书都没了」 |
| 面板里改了网址但规则不生效 | 规则直接读 `source.get('网址')` 而非走 `getsurl()` | 「改了没用」 |

**核心设计原则**：域名只能有一个真相源（single source of truth），并且这个真相源要能被「自动写回」。

---

## 2 三层架构

```
┌─────────────────────────────────────────────┐
│ L3 用户界面层  loginUi 按钮（3 个）           │
│     🚀一键选站  💍发布页取址  🌐站点快切      │
└──────────────────┬──────────────────────────┘
                   │ 写
┌──────────────────▼──────────────────────────┐
│ L2 存储层  source.putLoginInfo({'网址': u})  │
│     即登录面板「网址」输入框的值              │
└──────────────────┬──────────────────────────┘
                   │ 读（唯一入口）
┌──────────────────▼──────────────────────────┐
│ L1 解析层  getsurl()                         │
│     空值兜底 → 死域名检测 → 自动挑活站点      │
└──────────────────┬──────────────────────────┘
                   │ 被所有规则调用
      searchUrl / exploreUrl / ruleSearch / ruleBookInfo
      / ruleToc / ruleContent / gethd() / webck() ...
```

**关键约束**：**除 `getsurl()` 内部，任何地方都不许直接读 `source.get('网址')`**。
一旦破例，换域名就会漏改，出现「部分功能能用」。

## 3 核心函数 `getsurl()`（可直接抄）

```js
// jsLib 顶层（jsLib 里不能用 java.* 方法，只能拿 this 解构）
function getsurl() {
  const {java, source} = this;
  let surl = String((source.getLoginInfoMap() || {'网址': ''})['网址'] || '');
  surl = surl.replace(/\/$/, '');              // 去掉尾斜杠，避免拼出 //path
  // ① 空 → 用默认活站点
  if (!surl) return 'https://8xsk.cc';
  // ② 已知死域名 → 自动回退（探活后选第一个可用的）
  let dead = BX_DEAD.some(function(d){ return surl.indexOf(d) >= 0; });
  if (dead) {
    for (let i = 0; i < BX_POOL.length; i++) {
      if (this.bxSiteOk(BX_POOL[i])) {
        java.log('旧域名已失效，自动切换：' + BX_POOL[i]);
        return BX_POOL[i];
      }
    }
    return 'https://8xsk.cc';
  }
  return surl;
}

// 常量放 jsLib 顶层
var BX_POOL = ['https://8xsk.cc','https://18xsk.com','https://18xsk.cc',
               'https://bachashuku.org','https://bachashuku.com'];
var BX_DEAD = ['www.8xbook.org','8xbook.org','luoyacheng.ip-ddns.com','ip-ddns.com'];
```

**三个设计要点**：

1. **`BX_DEAD` 而不是「试所有」**：每次请求都探活 5 个站点会慢 5 秒。
   只对**已知死域名**做探活回退，正常域名零开销。
2. **`BX_POOL` 要有序**：按历史可用率排序，第一个是当前最稳的。
3. **空值必须兜底**：首次安装 / 用户清空输入框时不能让 `getsurl()` 返回空串，
   否则全站 URL 变成 `/modules/article/...` 相对路径 → 全部请求失败。

## 4 站点探活 `bxSiteOk()`（判据比状态码重要）

```js
function bxSiteOk(u) {
  const {java} = this;
  try {
    let hd = {'User-Agent': this.gethd()['User-Agent'] || 'Mozilla/5.0',
              'Cookie': 'age18_ok=1'};
    let b = String(java.connect(u + ',' + JSON.stringify({headers: hd, timeout: 9000})).body());
    // ★三重判据，缺一不可
    return b.length > 3000                       // ① 长度够（排除错误页/空响应）
        && b.indexOf('年龄确认') < 0              // ② 不是年龄闸门页
        && b.indexOf('八叉') >= 0;               // ③ 是本站（不是运营商劫持页）
  } catch (e) { return false; }
}
```

**为什么不能只看 HTTP 200**：

- 域名被劫持时返回 **200 + 运营商广告页**（长度够、状态码对，但内容不是本站）
- 年龄确认闸门返回 **200 + 确认页**（缺少 Cookie）
- 站点挂维护返回 **200 + 维护公告**

**通用做法**：长度下限 + 反例关键词 + 正例关键词，三条件与。

## 5 一键测速选站 `bxpick()`

```js
function bxpick() {
  const {java, source} = this;
  let pool = ['https://8xsk.cc','https://18xsk.com','https://18xsk.cc',
              'https://bachashuku.org','https://bachashuku.com'];
  let ua = this.gethd()['User-Agent'] || 'Mozilla/5.0';
  java.toast('正在测速 ' + pool.length + ' 个站点…');
  let ok = [], bad = [];
  for (let i = 0; i < pool.length; i++) {
    let u = pool[i];
    let t0 = new Date().getTime();
    try {
      let hd = {'User-Agent': ua, 'Cookie': 'age18_ok=1'};
      let b = String(java.connect(u + ',' + JSON.stringify({headers: hd, timeout: 12000})).body());
      let ms = new Date().getTime() - t0;
      if (b.length > 3000 && b.indexOf('年龄确认') < 0 && b.indexOf('八叉') >= 0)
        ok.push({u: u, ms: ms});
      else bad.push(u + ' (无效页 ' + b.length + 'B)');
    } catch (e) { bad.push(u + ' (不通)'); }
  }
  ok.sort(function(a, b){ return a.ms - b.ms; });     // ★按耗时升序
  if (!ok.length) {
    java.longToast('❌ 所有站点都不通\n' + bad.join('\n') +
                   '\n\n请检查网络，或点「💍网址」从发布页找新域名');
    return;
  }
  let best = ok[0];
  // ★写回登录信息（getsurl 读的就是这里）
  let Info = source.getLoginInfoMap() || {};
  Info['网址'] = best.u;
  source.putLoginInfo(JSON.stringify(Info));
  try { java.put('8xzx', ''); } catch(e) {}   // 顺带清旧缓存

  let lines = ['✅ 已选：' + best.u + '  ' + best.ms + 'ms', '────────'];
  for (let i = 0; i < ok.length; i++) lines.push('✅ ' + ok[i].u + '  ' + ok[i].ms + 'ms');
  for (let j = 0; j < bad.length; j++) lines.push('❌ ' + bad[j]);
  lines.push('────────');
  lines.push('已写入「网址」，直接返回即可使用');
  java.longToast(lines.join('\n'));
}
```

**要点**：

- **串行测速**（不用并发）：书源环境里 `java.connect` 并发容易触发风控；5 个站点 × 12s 超时上限 = 60s，可接受
- **结果全量展示**（成功+失败）：用户能看到「哪些死了」，比只说「已选 X」有信息量
- **排序后取 `ok[0]`**：不能取 `pool[0]`（可能是死的）
- **写回 `putLoginInfo`**：这样用户下次打开面板能看到新网址，不是「暗改」

## 6 发布页取址 `webfb()`（域名全死时的最后出路）

站点域名全换掉时（比如 8xsk.cc → 新家族），`BX_POOL` 里的都失效了，只能从**发布页**（地址发布页/防失联页）找。

```js
function webfb() {
  const {java, source} = this;
  java.toast('正在打开发布页…');
  let option = {};
  option['headers'] = gethd();
  option['timeout'] = 15000;
  let htm = '';
  // ★不走 webView（该通道被网络环境阻断），纯 HTTP 即可拿到发布页
  try { htm = String(java.connect(fbyurl + ',' + JSON.stringify(option)).body() || ''); }
  catch(e) { java.longToast('请求发布页失败：' + String(e).substring(0,80)); return; }
  if (/^java\.net|^error/.test(htm) || htm == '') {
    java.longToast('网络连接异常\n可点「🚀一键选站」自动测速');
    return;
  }
  // ★选择器兜底：不同模板可能是 #url-list>li>a 或普通 a[href]
  let urls = [];
  try {
    let j = Packages.org.jsoup.Jsoup.parse(htm);
    let as = j.select('#url-list>li>a');
    if (as.size() == 0) as = j.select('a[href^=http]');
    for (let i = 0; i < as.size(); i++) {
      let u = String(as.get(i).attr('href') || '');
      // ★只保留本站家族域名
      if (u && u.indexOf('8xsk') >= 0 || u.indexOf('bachashuku') >= 0 || u.indexOf('18xsk') >= 0) {
        if (urls.indexOf(u) < 0) urls.push(u);
      }
    }
  } catch(e2) {}
  java.log('发布页找到 ' + urls.length + ' 个站点：' + urls.join(' '));

  // ★注入「复制」按钮，让用户能手动粘贴到「网址」框
  htm = htm.replace('</body>', `<script>
function copyt(t) {
  var texta = document.createElement('textarea');
  texta.value = t; texta.style.position = 'fixed'; texta.style.left = '-9999px';
  document.body.appendChild(texta); texta.select();
  document.execCommand('copy');
  alert('已复制\n' + t);
}
document.querySelectorAll('a[href^="http"]').forEach(function(x){
  if (x.nextElementSibling && x.nextElementSibling.tagName === 'BUTTON') return;
  x.insertAdjacentHTML('afterend', '<button style="margin:4px;padding:4px 10px;border-radius:4px;border:1px solid #888;background:#2a6;color:#fff" onclick="copyt(\'' + x.href + '\')">复制</button>');
});
</script>` + '</body>');

  try { java.startBrowser('data:text/html;base64,' + java.base64Encode(htm), '获取网址'); }
  catch(e3) { java.longToast('打开浏览器失败：' + String(e3).substring(0,60)); }
}
```

**三个关键技术点**：

1. **`java.connect` 而不是 `webView:true`**
   实测该站点用 `webView:true` 抓发布页 **被网络环境阻断**（连 about:blank 都超时 60s），
   而纯 HTTP `java.connect` **406ms 拿到 7 个站点**。
   ⇒ **凡「webView 抓取」失败，先换纯 HTTP 试一次**，不要立刻断定「站点被墙」。

2. **`data:text/html;base64,` + `startBrowser`**
   把改造后的 HTML（注入复制按钮）编码成 data URI 交给内置浏览器。
   好处：用户看到的是**带复制按钮的发布页**，不用长按选文字。
   ⚠️ 注意 data URI 有长度限制，发布页通常几十 KB，安全。

3. **域名白名单过滤**
   发布页常混入「友链/广告/统计」链接，必须按域名特征过滤（`8xsk` / `bachashuku` / `18xsk`），
   否则用户复制到广告站，粘进去还是打不开。

## 7 手动快切 `bxs(x)`（序号索引，供按钮复用）

```js
function bxs(x) {
  const {java, source} = this;
  let pool = ['https://8xsk.cc','https://18xsk.com','https://18xsk.cc',
              'https://bachashuku.org','https://bachashuku.com'];

  m['网址'] = u;
  source.putLoginInfo(JSON.stringify(m));
  try { java.put('8xzx', ''); } catch(e) {}

```

配合 `loginUi` 里 5 个按钮：

```js
{name: '① 8xsk.cc',  type: 'button', action: 'bxs(0)'},
{name: '② 18xsk.com', type: 'button', action: 'bxs(1)'},
{name: '③ 18xsk.cc',  type: 'button', action: 'bxs(2)'},
```

## 8 「网址」输入框（用户可手填）

```js
{name: '网址', type: 'text', action: 'clrc()'},   // 值变了就清缓存
```

**为什么 `action` 要清缓存**：域名一变，所有以域名派生的缓存（目录/正文）都失效，
不清会读到旧域名的缓存结果 → 表现为「换了域名还是打不开」。

**输入框必须能被 `getsurl()` 读到**：靠 `source.getLoginInfoMap()['网址']`，
这是 Legado 官方机制（`loginUi` 的 `text` 行值存在 `loginInfo[name]`）。

## 9 缓存清理 `clrc()`

```js
function clrc() {
  const {java, source, cache} = this;
  let keys = ['8xid','8xzx','8xzxt','8xhmd','baxxq','bxvip','baxtime','baxtime2'];
  let n = 0;
  for (let i = 0; i < keys.length; i++) {
    try { cache.deleteMemory(keys[i]); n++; } catch(e) {}
    try { cache.delete(keys[i]); } catch(e) {}
  }
  // ★保留登录态
  try {
    let ck = ckget(source);
    if (ck) source.putLoginHeader(JSON.stringify({Cookie: ck}));
  } catch(e) {}
  java.longToast('已清理 ' + n + ' 项缓存\n（登录态与设置保留）');
}
```

**`deleteMemory` + `delete` 双调**：内存缓存和持久缓存是两套，只清一个会出现「重启后又变回旧值」。

## 10 重置 `reset()`（保留用户资产）

```js
function reset() {
  const {java, source} = this;
  let keep = source.getLoginInfoMap() || {};
  let acct = String(keep['账号'] || '');
  let pwd  = String(keep['密码'] || '');
  let ks = ['8xdn','8xsj','8xsm','8xjhf','bx调试模式'];
  let c1 = String(keep['封面背景颜色'] || '');
  let c2 = String(keep['封面字体颜色'] || '');
  for (let i = 0; i < ks.length; i++) {
    try { source.put(ks[i], '0'); } catch(e) {}
  }
  try { source.removeLoginHeader(); } catch(e) {}
  try {
    let site = getsurl();
    cookie.setCookie(site, 'age18_ok=1');    // ★只留年龄 Cookie
  } catch(e) {}
  // ★账号/密码/网址/颜色全部保留
  try {
    let m = {'账号': acct, '密码': pwd, '网址': String(keep['网址'] || '')};
    if (c1) m['封面背景颜色'] = c1;
    if (c2) m['封面字体颜色'] = c2;
    source.putLoginInfo(JSON.stringify(m));
  } catch(e) {}

```

**「重置」最忌一键清空**：用户会丢掉账号密码和线路配置，体验极差。
**正确做法**：只重置「开关/登录态」，保留「身份/线路/个性化」。

## 11 登录面板（loginUi）设计规范

### 11.1 分组与视觉分隔

35 个按钮必须分组，否则用户找不到。用**分组标题按钮**（无 action，只做提示）：

```js
{name: '──────── 线路 ────────', type: 'button', action: 'java.toast("线路区")'},
```

或用空行 `{name: '', type: 'button', action: ''}`。

### 11.2 输入框与按钮的配对

| 类型 | 用途 | action 时机 |
|---|---|---|
| `text` | 网址/账号/密码/书名黑名单 | **值改变时**（600ms 防抖） |
| `button` | 所有操作 | 点击时 |

**`text` 的 `action` 是「值变化回调」**，不是点击回调——这是很多人写错的地方。

### 11.3 面板环境的三条铁律（源码级）

| 环境 | 可用绑定 | 不可用 |
|---|---|---|
| `loginUi` 的 `<js>` 生成器 | `result` / `book` / `chapter` | **`source` / `java` / `infoMap` 全无** |
| 按钮 `action` | `java`（SourceLoginJsExtensions） | **`source` 无** |
| 规则 `@js:` | `java` / `source` / `baseUrl` / `result` 等完整 | — |

⇒ **`loginUi` 若是 `<js>` 动态生成，生成函数必须无参且不访问 `source`**，
否则抛 `ReferenceError` → **整个登录界面渲染失败**（用户看到「界面打不开」）。

⇒ **按钮 action 里不能写 `source`**，要用 `java`（`java.put/get` 与 `source.put/get` 同一键空间）。

### 11.4 提示信息要「可操作」

❌ 差：`java.toast('失败')`
✅ 好：

```js
java.longToast('\n❌ 未检测到登录 Cookie\n\n可能原因：\n1) 浏览器里没登录成功\n2) 登录后提前返回了\n\n可再点一次「🌐网页登录」，登录成功后停留 2 秒再返回');
```

**长提示用 `longToast` 而不是 `toast`**：`toast` 显示时间短，多行内容看不清。

## 12 诊断按钮 `lgdiag()`（7 步排障）

用户报「登录不上」时，让他点一下诊断按钮，一次拿到全部信息：

```js
function lgdiag() {
  const {java, source, cookie} = this;
  let out = [];
  let nn = getsurl();
  out.push('【1】线路：' + nn);

  // 2 登录页可达性
  let lgHtml = '';
  try {
    let opt = {}; opt['headers'] = gethd();
    lgHtml = String(java.ajax(nn + '/login.php,' + JSON.stringify(opt)) || '');
    out.push('【2】登录页：' + (lgHtml ? (lgHtml.length + ' B') : '失败'));
    if (lgHtml && lgHtml.indexOf('frmlogin') >= 0) out.push('     ✅ 含登录表单');
    else if (lgHtml) out.push('     ⚠️ 无登录表单');
  } catch(e) { out.push('【2】登录页异常：' + String(e).substring(0,50)); }

  // 3 验证码地址（藏在 onfocus 属性里）
  let codeUrl = '';
  try {
    let wj = Packages.org.jsoup.Jsoup.parse(lgHtml);
    let cands = [
      String(wj.select('#checkcode').attr('onfocus') || ''),
      String(wj.select('img[name=imgccode]').attr('onclick') || ''),
      String(wj.select('#t_imgccode').attr('onclick') || '')
    ];
    for (let ci = 0; ci < cands.length; ci++) {
      let mm = String(cands[ci] || '').match(/['"]([^'"]*checkcode\.php[^'"]*)['"]/i);
      if (!mm) continue;
      codeUrl = mm[1];
      if (codeUrl.indexOf('http') != 0) codeUrl = nn + '/' + codeUrl.replace(/^[/]+/,'');
      codeUrl = codeUrl.replace(/[+].*$/, '');
      if (codeUrl) break;
    }
    out.push('【3】验证码地址：' + (codeUrl || '未找到'));
  } catch(e) { out.push('【3】解析失败：' + String(e).substring(0,50)); }

  // 4 验证码图片（hex 通道判魔数）
  if (codeUrl) {
    try {
      let r = java.connect(codeUrl + ',{"type":"hex","headers":{"Cookie":"age18_ok=1"}}');
      let hex = String(r.body() || '');
      let isPng = hex.substring(0,8) == '89504e47';
      let isJpg = hex.substring(0,6) == 'ffd8ff';
      let isGif = hex.substring(0,6) == '474946';
      out.push('【4】验证码图片：' + hex.length + ' hex | ' +
               (isPng?'PNG':isJpg?'JPEG':isGif?'GIF':'未知'));
    } catch(e) { out.push('【4】验证码图片失败：' + String(e).substring(0,50)); }
  }

  // 5 CookieJar
  let jar = '';
  try { jar = String(cookie.getCookie(nn) || ''); } catch(e) {}
  out.push('【5】CookieJar：' + (jar ? (jar.length + ' B') : '空'));
  out.push('     age18_ok：' + (jar.indexOf('age18_ok') >= 0 ? '有' : '无'));
  out.push('     jieqiUserInfo：' + (jar.indexOf('jieqiUserInfo') >= 0 ? '有（已登录）' : '无（访客）'));

  // 6 登录头
  let hdr = ckget(source);
  out.push('【6】登录头：' + (hdr ? (hdr.length + ' B') : '空'));
  out.push('     含 jieqiUserInfo：' + (hdr.indexOf('jieqiUserInfo') >= 0 ? '是' : '否'));

  // 7 表单值
  let df = lgForm();
  out.push('【7】账号：' + (df.u || '(空)'));
  out.push('     密码：' + (df.p ? '已填' : '(空)'));

  java.log(out.join('\n'));
  java.longToast(out.join('\n'));
}
```

**诊断按钮的设计原则**：

- **每一步都有明确结论**（✅/⚠️/❌），不是只打印原始数据
- **同时输出到 log 和 longToast**：log 可复制给我，toast 用户能当场看
- **覆盖完整链路**：线路 → 页面 → 验证码 → Cookie → 登录头 → 表单值

## 13 避坑清单（K1~K12）

| 编号 | 坑 | 症状 | 解法 |
|---|---|---|---|
| **K1** | 规则里直接 `source.get('网址')` | 换了域名部分功能还走旧域 | 全部改走 `getsurl()` |
| **K2** | `getsurl()` 空值不兜底 | 首次安装全站 404 | `if (!surl) return '默认站点'` |
| **K3** | 探活只看状态码 | 劫持页/闸门页被当成功 | 长度+反例+正例三判据 |
| **K4** | 每次都探活整个池 | 每次请求慢 5 秒 | 只对 `BX_DEAD` 探活 |
| **K5** | `webView:true` 抓发布页 | 超时 60s 被判定站点死 | 换纯 HTTP `java.connect` |
| **K6** | 发布页链接不过滤 | 用户复制到广告站 | 域名特征白名单 |
| **K7** | 换域名不清缓存 | 读到旧域名缓存 | `java.put('8xzx','')` + 清目录缓存 |
| **K8** | 重置按钮清空账号密码 | 用户要重新登录 | `reset()` 保留身份/线路 |
| **K9** | `text` 的 action 当点击回调写 | 点击输入框没反应 | text 的 action 是「值变化」回调 |
| **K10** | `loginUi` 的 `<js>` 里访问 `source` | 登录界面完全打不开 | 生成函数无参、不访问 source |
| **K11** | 按钮 action 里写 `source.put` | 静默失败（点击无反应） | 改 `java.put`（同键空间） |
| **K12** | `cookie.setCookie(url, str)` 整体替换 | 年龄 Cookie 被冲掉 → 又变确认页 | 先 getCookie 全文再合并回写 |

## 15 移植清单（换到别的站要改什么）

| 项 | 位置 | 改法 |
|---|---|---|
| `BX_POOL` | jsLib 顶层 | 换成目标站家族域名 |
| `BX_DEAD` | jsLib 顶层 | 换成已知死域名 |
| `bxSiteOk` 判据 | jsLib | 长度阈值 + 本站特征词 |
| `webfb` 的 `fbyurl` | jsLib 顶层 | 换成目标站发布页 |
| `webfb` 域名白名单 | `webfb()` 内 | 换特征词 |
| `bxs` 的 pool | loginUrl | 与 `BX_POOL` 同步 |
| `loginUi` 按钮序号 | loginUi | 与 pool 顺序一致 |
| 年龄/准入 Cookie | `gethd()` | 换目标站要求的 Cookie |

**不用改的**：三层架构、`getsurl()` 逻辑、测速排序、诊断框架、重置保留策略。
