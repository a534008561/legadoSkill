## 0. 站点与协议契约（全实测）

| 项 | 值 |
|---|---|
| 主域 | `yutinglu.com`（备用基础域 `xiangxung.com` 已 DNS 不存在/退役） |
| 搜索 | `https://s.yutinglu.com/v4/1/lists.api?keyword={{key}}&form=1&page={{page}}` |
| 详情 | `https://d.yutinglu.com/book/details/v4/{floor}/{id}.html`，floor=id 去掉末 3 位 |
| 线路(source) | `https://d.yutinglu.com/book/source/v4/{floor}/{id}.html` |
| 目录(catalog) | `https://catalog.yutinglu.com/{site_path}` |
| 正文 | `https://chapter.yutinglu.com/{catalog[].path}` |
| 书城 | **`https://book.yutinglu.com/`**（不是 d.！ProxyPin 抓包实锤） |

**主协议** `D(jv,c)`：base64 解码 = 16B 可见 Base32 seed + 16B IV + N×16B AES-256-CBC 密文 + 16B tail；`key=SHA256(seed)`、`AES/CBC/NoPadding`；首块明文被 IV 覆盖，按端点补 JSON 前缀（`F()`）。含中文时 `D()` 返回 latin1 串，需 `D8()` 二次反解 UTF-8。

**正文短密文 = MkAES**：`AES/CBC/PKCS5Padding`，key=`Pxga!h*e4@T8xfOm`，IV=`E&z!EHGLd$fli*8R`（去加固 APK 的 `me.jessyan.art.encrypt.MkAES` 硬编码常量）。脱壳 dex 里 `CatalogRepository.lambda$getArtChapterContent$4` 实锤 `is_encrypt` 时 name+content 都过 `MkAES.getInstance().decrypt()`；`MkCatalog.getName()` 同密钥解目录章节名。干扰项 `MkShapeUtils.decryptBook(SHA256('hyy001'))` 只被 UserPresenter 用，对照实验解正文必 BadPadding。

## 1. 六个关键修复（按发生顺序）

### ① 搜索「东京」只剩 2 条、有本打不开（v4.1）
搜索响应 100 条里**仅第 1 条字段名 `id`、其余 99 条 `book_id`**（覆盖率 1/99）。旧 `bookList` 只取 `o.id` ⇒ 99 条拼成 `.../undefined/undefined.html` 被过滤。
修：`bid=o.id||o.book_id` + `/^\d+$/` 校验 + 写回 `o.id`。跨 5 关键词 100/100 有效。
**不是多域名问题**：`xiangxung.com` 全 `UnknownHostException`，conf 的 `secondary_domain` 全空。

### ② 「我在东京克苏鲁」少一条线路（v4.2）
主协议首块被 IV 覆盖时，第 1 个 source 对象开头 16B（`{"site_id":"bqk"`）被吃掉，`OBJS()` 的 `lastIndexOf('{')` 返回 -1 静默跳过 ⇒ 5 个锚点只解析 4 条。
修：首个锚点前无合法 `{` 时取残片、从 `crawl_book_id` 起剥前缀、按 `site_path` 首段补 `site_id` 拼合法 JSON。8 本书 parsed=anchor 零重复。

### ③ 书籍变量切线路不生效（STV 范式 + 作用域坑）
`book` 绑定只在规则 `@js` 环境（`AnalyzeRule.kt:834`），jsLib 共享 scope 里没有 ⇒ `CVAR()` 恒返回空、永远默认线路 1。STV 成品 `jsLib` 长度=0、`cvar()` 内联在三条规则里是决定性对照。
修：`CVAR(bk,jv)`/`SEL(L,bk,jv)` 由 init/chapterList 显式传 `(book,java)`；四级兜底（getCustomVariable/getVariable('custom')/bk.variable/java.get('custom')）。源码核实 `putCustomVariable(v)=putVariable("custom",v)`，键名 `custom` 无误。线路真值不拼进 `tocUrl?line=`（BookInfo.kt 每次刷新会重写）。

### ④ 发现页：select 切男女频 + 排行榜置顶 + 二级分类（v5）
`classify/v4/index.html` 解密后 male 14 类 84 子类 / female 10 类 57 子类；分类 URL 第 3 段是 `stype`（-1=全部）。`exploreUrl` 改 `@js:` 动态 `MYKINDS(infoMap,java,cfg)`，分类树烘焙进 `MYTREE` 常量。

### ⑤ 切频道不自动刷新 → rrssk 的 `java.refreshExplore()`（v5.1）
rrssk 成品 select action 是 `SET('server',infoMap['域名']); java.refreshExplore()`（清 kinds 两级缓存并重绘），不是 `reUiView`。状态栏用 `viewName` 动态显示当前频道。

### ⑥ 布局：折叠分组 + 自动宽度（v5.3 → v5.4 终版）
- **91Hub 折叠**：`type:button` 折叠条 → `source.getVariable()` 读 → 只翻转本次 key 写回 → `java.refreshExplore()` 重绘；求值端 `(cfg[key]===undefined)?defOpen:(cfg[key]!==0)`，标题 `▾/▸`。⚠ 必须先解析原串**保留 `time/domains` 等已有配置**。
- **自动宽度（用户纠正「不用算，阅读里有自动的」）**：`FlexChildStyle.kt` 默认 `layout_flexBasisPercent=-1F`（WRAP_CONTENT 自动按内容测量）、`layout_flexGrow=0F`。⇒ **所有发现项 `style:{}` 不写 basis/grow**，只给分组标题/折叠条/select 写 `layout_wrapBefore:true`。我前三轮手工算 `t.length`（`🏆 人气榜` UTF-16=6 被判 5 字→basis 0.99 独占整行）全是错路。
- **check_source「发现规则为空」**：`CheckSourceService.kt` 取 `firstOrNull{!it.url.isNullOrBlank()}`；默认全收缩会 0 个 url，且校验器裸环境 `source.getVariable()` 抛错会让整段 `@js:` 返回空 ⇒ 排行榜默认展开 + 「📚 书城精选」常驻首项固定放在所有折叠条之前 + `exploreUrl` 整段 try/catch 兜底。

## 3. jsLib 函数速查

| 函数 | 用途 |
|---|---|
| `D(jv,c)` / `D8(jv,c)` | 主协议解密（D8 多一层 latin1→UTF-8） |
| `F(s,kind)` | 首块被覆盖时按端点补 JSON 前缀 |
| `P2(jv,t,kind)` / `P8(jv,t,kind)` | 响应→对象（P8 含中文与 source 残对象兜底） |
| `MK(jv,c)` / `MN(jv,n,i)` / `MC(jv,t)` | MkAES 正文解密 / 章节名 / 逐行广告清洗 |
| `OBJS(raw,anchor)` / `BOOKS(raw)` | 首块被 IV 覆盖时逐对象括号配平提取 |
| `EX(jv,result)` | 发现页统一书籍列表 |
| `CVAR(bk,jv)` / `SEL(L,bk,jv)` / `SRCLIST(L,sel)` | 书籍变量选线路 + 简介线路列表 |
| `MYKINDS(im,jv,cfg)` | select 切频道 + 91Hub 折叠 + 自动宽度发现页 |

## 4. 铁律清单

1. jsLib 里**不能裸用** `java` / `book` / `source` / `infoMap` 等规则环境绑定 —— 一律 `function X(jv,bk,...)` 由规则显式传参。
2. 主协议首块被 IV 覆盖 ⇒ 猜前缀救不回时用**逐对象括号配平**，别穷举前缀。
3. 「列表大小 N 但书籍总数≪N」先统计**字段覆盖率**（id vs book_id），别先怀疑域名/限频。
4. 发现页要自适应：**不要写 basis/grow**，默认 -1/0 就是自动；只给分组标题写 `wrapBefore:true`。
5. select/折叠改变列表：用 **`java.refreshExplore()`**（rrssk），不用 `reUiView`。
6. 动态 `exploreUrl` 改折叠后必须留**常驻 url 首项** + 整段 try/catch，否则 check_source 报「发现规则为空」。
7. 折叠状态写 `source.setVariable()` 前必须**解析原串保留其它字段**。
8. 改完 `exploreUrl` 要发现页长按菜单「刷新」清两级缓存。

⚠️ 最终必须在 Legado APP 内实测：搜索 → 详情（简介线路列表）→ 设置书籍变量换线 → 刷新目录 → 正文；发现页切频道、点 `▸ 历史` 展开子项。
