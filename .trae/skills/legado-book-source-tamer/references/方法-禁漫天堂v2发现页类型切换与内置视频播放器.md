# 方法-发布页泛子域站四模式发现页与内置视频播放器重建（禁漫天堂 v2）

> 261128 实战蓝本：jmtt1.net 书源从 v1（三模式 + startBrowser 看视频）整体重建为 v2（漫画/小说/视频/短剧四模式 + 发现页类型切换/原站筛选/榜单 + 内置视频播放器 + 线路测速切换）。
> 成品 `examples/禁漫天堂_jmtt_v2_四模式.json`（32.7KB），LT(1122) 与 legado-E(1125) 双端落库；LT check_source 1/1、MCP debug 搜索/详情/目录/正文/发现列表/榜单全绿；E 真机 `/refreshToc`+`/getChapterList`+`/getBookContent` 三形态全绿，书架 book.type 实测 小说=8 / 漫画=64 / 视频=4。

## 1. 站点新契约（发布页 → 泛子域 → 四频道）

- `https://jmtt1.net` 在沙盒与 App 均 **TLS 握手被重置（SNI 阻断）**，但 `jmtt2.net` 与 `18mh.co` 返回同一发布页；登录面板发布页默认给 `jmtt2.net` 并允许用户改。
- 发布页 JS：`words = '306个英文词'.split(',')`，线路为 `location.protocol + '//' + words.random() + '.tekovaki.cc'` ⇒ **不要写死旧后缀 `yyc2mhau.cc`**，用正则从发布页提取：`/words\.random\(\)\s*\+\s*'\.([a-z0-9.\-]+)'/`。默认线路 `abandon.tekovaki.cc`。
- 内容频道：`/comic` 漫画、`/novel` 小说、`/mv` 视频、`/drama` 短剧；四类共用一套卡片/详情/目录结构。
- **搜索**：`/search/{encodeURIComponent(key)}` 全站混排，条目 `a.jm-rrow`（`data-type=comic|novel|video`），分页 `/search/{kw}/page/N`；单类型搜索 `/{seg}/search/{kw}`。
- **列表**：`/comic/all`、`/novel/all`、`/mv/all`、`/drama/all`，`li.jm-card` / `li.jm-vcard`；排行榜 `/{seg}/rank`（服务端直出 popular-day，`?period=day|week|month|year` 切周期，其它榜别是 JSON API `/rank/board?theme=&sort=&period=`）。
- **筛选 URL 契约（重要）**：分类/标签是真链接；`status`/`length`/`subtitle`/`duration` 是查询参数；排序是**路径** `/{seg}/hot|freshest|last_published|collect`。非默认排序**会丢分类**（站点自身行为，不要试图用 `/novel/hot/xycs`，实测 404）。分页 `/{seg}/all/page/N`，而 `/{seg}/hot/N`（`/hot/page/N` 404）。
- 小说 `status=2` 连载、`1` 完结；漫画 `status=1` 连载、`2` 完结（两者相反，别复用）。

## 2. 发现页架构：类型切换 + 原站筛选 + 榜单

`exploreUrl` 用 `@js:` IIFE 返回 JSON 字符串，按 `infoMap['类型']` 生成当前类型的行：

1. `select 类型`：漫画/小说/视频/短剧，`action: "java.refreshExplore()"`。
2. `select {类型}分类`：从站点筛选栏抄全部分类；小说额外含 `/novel/original` 原创。
3. 原站筛选：小说 `toggle 状态` + `select 字数` + `select 排序`；视频 `toggle 字幕` + `select 时长` + `select 排序`；漫画 `toggle 状态` + `select 排序`；短剧 `select 时长` + `select 排序`。
4. `select {类型}榜单`：人气日/周/月/年榜。
5. `url` 列表入口 + `url` 榜单入口（标题拼接当前筛选，方便用户确认）。

关键机制：

- **select/toggle 的 action 必须是单个字符串**，写数组会让 GSON 解析失败、标签变列表不变；`java.refreshExplore()` 是 LT/E 都存在的官方通道（SourceLoginJsExtensions.refreshExplore → callback.reUiView）。
- **URL 不写死 host**：入口 URL 写成 `{{jmHost(source)}}/{seg}/all{{page>1?('/page/'+page):''}}?status=2`。AnalyzeUrl 在**请求时** evalJS，`source` 已绑定 ⇒ 登录面板切线路后，连**已经缓存的发现页入口**也会跟随新线路。
- **榜单没有分页（top30）**：`{{page>1?(jmHost(source)+'/search/__jmrank_end__'):(jmHost(source)+'/novel/rank?period=day')}}`，第2页落到 0 结果页，避免上滑无限重复榜单。该搜索页实测 200 + 0 条。
- 发现页字段统一用 @js + `String(result)` 正则（兼容 `li.jm-card` / `li.jm-vcard` / `a.jm-rp-stand` / `a.jm-rkrow` 四种条目）；`bookUrl` 返回相对 href，由 BookList 解析成当前线路绝对地址。

## 3. 目录页完成 book.type 分类 + 视频内置播放器

- `ruleToc.chapterList` 的 @js 里按 `baseUrl` 路径设 `book.type`：`/comic/`→64、`/novel/`→8、`/mv/` 或 `/drama/`→4。**必须在 chapterList 重设**（`WebBook.getBookInfoAwait/getChapterListAwait` 每次 removeAllBookType→addType(source type)），E 真机书架实测三种类型正确。
- 漫画/小说目录：从 `data-jm-dt-panel="chap"` 锚点开始扫到 `data-jm-dt-panel="cmt"`，避开 meta 区「最新章节」链接；返回 `new Packages.java.util.ArrayList()`，每项 `JSON.stringify({title,url})`，字段规则 `$.title` / `$.url`（LT/E 双版本通吃；E 无 NativeArray 分支）。
- 视频/短剧：**单章**，标题 `▶ 作品名`，URL = 当前线路 + 详情 path。
- 视频正文不再 `java.startBrowser`：详情页 `const _detail_ = {...}` 里有 `"url":"/media/m3u8?url=...&exp=...&token=..."`，@js 直接返回 `jmAbs(source,p) + ',{"headers":{"User-Agent":"..."},"timeout":20000}'`。LT `VideoPlay` 会 `content.trim()` → `AnalyzeUrl` 解析 URL 选项 → `player.mapHeadData` 给 ExoPlayer；E 的 `/getBookContent` 同样返回该 URL（前缀 U+3000 是 Legado 自动缩进，`trim()` 会处理）。
- `/media/m3u8` 代理返回标准 HLS（AES-128 key + 绝对 ts CDN URL），实测分段可取；不用 code 层解密。

## 4. 图片代理与三个静默失败坑

- 图片统一走 `/social-cover/{base64(URL path)}.{ext}`，**base64 必须去掉 `=` 填充**（带 `==` 会 301→404）；ext 取原扩展名（jpg/png/webp/gif）。登录面板提供「🖼 图片代理 开/关」按钮，兼容不同网络的 Glide 栈差异。
- ★★ **Rhino 里 Java String 不能直接 `.replace(/regex/,'')`**：`java.base64Encode(p)` 返回 Java String，直接调 JS replace 抛异常；被 try/catch 吞后图片**静默退回图床直链**（用户网络白图）。修法 `jmStr(java.base64Encode(p)).replace(/=+$/,'')`。
- ★★ **覆盖同名书源时 source variable 不覆盖**：v1 遗留 `jmHost=w9xfv.yyc2mhau.cc` 劫持了 v2 搜索（症状像"新规则没生效"）。修法＝新版本所有变量名加版本前缀 `jmV2Host/jmV2Pub/jmV2LineN/jmV2LatN/jmV2ImgProxy`，绝不再读旧 key。
- ★★ **登录面板输入框真值在 `result` Map**：V1 button action 里 `java.get(name)` 读的是**已保存的源变量**，不是用户刚输入的值；App 把当前表单 Map 绑成 `result`（LT `handleButtonClick`、E `SourceLoginDialog` 均如此）。action 写 `jmFetchLines(java, result)`，函数内先 `jmMapGet(result,'jmPub')`，再回退 `java.get('jmV2Pub')`、再回退默认。
- ★ 作者链接里含 `<svg>`：`<a href=".../author/..."><svg>...</svg>蓝天白云</a>`，`>([^<]+)<` 会取空并误命中侧栏别处。修法＝限定 `jm-dt-info` 块 + `([\s\S]*?)</a>` + 去标签。

## 5. 登录面板（全按钮 Toast）

发布页输入框 + 📡一键取线(自动测速选最快) + 📶测速全部(ms 回填按钮) + 🩺线路检查 + 🌐状态 + 🖼图片代理开关 + 6 个线路按钮（每个点击先测该线、可达才切换）。测速用 `/favicon.ico` GET + `Date.now()`，失败判据是返回串含 `Exception/java./Caused by`（`java.ajax` 错误返回堆栈串而不是抛）。发布页解析：`words` 词表 + `'\.suffix'`；候选 = `abandon.suffix` + 5 个随机词。搜索间隔用 `concurrentRate=1/1000`，面板测速不要高频点。
